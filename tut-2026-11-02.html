1.7 个 AI 副业赚第一桶金：从免费工具起步的 30 天计划

作者花几个月实测 AI 工具后总结的 7 条新手副业：AI 辅助自由写作、无脸短视频、卖数字产品、社媒代运营、给小企业搭聊天机器人、简历与领英改造、博客与 newsletter，全部可用免费 AI 账号起步，目标是 30 天赚到第一个 100 美元。

3 步上手：
  1. 按作者的 30 天计划：第一周只选 1 个方向、在 2–3 个模型上测试提示词
  2. 第二周去 Fiverr、Etsy、Gumroad、Reddit 验证同类卖家存在（有卖家即有付费市场）
  3. 第三周交付第一件作品：一个 gig、一款产品或 10 条短视频，第四周凭反馈迭代

来源：Medium 教程

变现角度：提示词本身就能卖：把每个副业验证过的提示词打包成“开箱即用包”卖，作者文中就附了 300 条可复制提示词的引流产品。先卖工具包，再卖服务。

2.别追 AI 副业了：每周 7 小时，建一个能反复卖的资产

作者算了一笔账：每周 7 小时、时薪 30 美元的自由职业，一个月也只有 840 美元，一旦没单就断流；更糟的是降价竞争会把时薪压到 15 美元。他的解法是建“AI 资产”：模板包、 playbook、提示词系统，做一次、反复卖。

3 步上手：
  1. 用作者给的 Claude 提示词列出你每周重复 30 分钟以上的 10 项任务
  2. 找出其中“你的答案会和 AI 不一样”的那一项——那就是只有你能做的产品创意
  3. 把这个任务做成一页模板或清单，先免费发给 10 个同行验证有人愿付费

来源：Medium（AI Trends 24）

变现角度：卖时间的天花板是你的小时数，卖资产的天花板是分发量。把本职工作中的重复流程产品化，是普通人最现实的 AI 变现路径。

3.Notion 模板副业：一个周末起步，瞄准 1000 美元/月

作者筛选后认为 Notion 模板是门槛最低的数字产品：不用写代码、不用大流量，生产力工具市场够大，顶级创作者在 Gumroad 与 Etsy 上每月悄悄赚几千美元。关键是选超细分的职业人群，而非做通用模板。

3 步上手：
  1. 用 AI 做市场调研：让 ChatGPT/Claude 列出 5 个高度依赖整理但没时间自建系统的细分职业及各自 3 个日常痛点
  2. 针对一个痛点做模板：仪表盘、数据库、追踪器三件套齐全，界面先做干净再谈功能
  3. 在 Notion 开“Share to Web + 允许复制为模板”，上架 Gumroad/Etsy，用 30 秒录屏在 TikTok 与短视频平台演示

来源：Medium 教程

变现角度：模板是 100% 毛利的数字资产：一次制作、无限复制。先送精简版换邮箱，再卖完整版，是这篇教程验证过的免费流量打法。

4.本地 AI 工具榜：自己跑模型，省下订阅费

11 月 2 日更新的本地 AI 榜单按 GitHub 星标增速排名：自托管求职应用、桌面本地 AI 工作室、本地大模型推理、轻量 Agent 等。共同点是数据不出本机、不依赖第三方 API，适合对隐私敏感的场景。

3 步上手：
  1. 按榜单挑一个与你需求最贴的工具（如离线语音转文字、本地聊天界面），先看其 README 的硬件要求
  2. 在自己的电脑或闲置主机上部署，优先选一键 Docker 或单文件方案
  3. 把原来按月付费的云端工具替换掉，记录每月省下的订阅费作为收益

来源：FindaRepo 11 月榜单

变现角度：“帮别人部署本地 AI”本身就是服务：律所、诊所、小公司都想要数据不出域，按部署加维护收年费，零 token 成本就是毛利。

5.GitHub 本周热榜：跨会话记忆 Agent 与反 AI 味设计 Skill 最火

第 45 周（11 月 2–8 日）GitHub Trending 存档显示：跨会话持久记忆 Agent（claude-mem，本周 +5.9K 星）、反 AI 味设计 Skill（hallmark，本周 +11.6K 星）与设计语言 Skill（impeccable，本周 +12K 星）领跑，说明 Agent 的竞争已从“能干活”转向“记得住、有品味”。

3 步上手：
  1. 给你的 Claude Code/Codex 装一个记忆类 Skill，让 Agent 跨会话记住项目上下文
  2. 再装一个设计类 Skill，专门修掉 AI 生成界面的“塑料感”
  3. 在下一个真实项目里对比：有记忆与设计的 Agent 输出，返工次数是否下降

来源：GitHub Trending 存档（第 45 周）

变现角度：把“记忆 + 品味”做成交付标准：接 AI 开发外包时，承诺可复用的记忆配置与设计规范，比单纯堆功能更容易拿到复购。

6.照着 DeepSeek Super-Agent，给团队搭一个主动式编码助手

DeepSeek 10 月 31 日开源的 Super-Agent 原型展示了一种新分工：Router 常驻监听仓库与群聊，Worker 并行干活并直接回 PR，Watchdog 盯着失败与死循环。官方标注为研究原型、非生产就绪，但架构本身可以直接借鉴。

3 步上手：
  1. 克隆 dsh-superagent-prototype，按 README 准备专用 GitHub 账号、Node.js 22.19+ 与 GitHub CLI
  2. 先在非核心仓库试跑：让 Router 接一个小需求，看 Worker 的 PR 质量与 Watchdog 表现
  3. 确认隔离方式（官方建议用独立系统账号运行）后再接入团队日常仓库

来源：DEV 教程

变现角度：把这套“监听—分发—并行执行”做成团队内部的自动化服务：按仓库接入数收费，或卖给小团队当“AI 值班开发”。

7.AI 自动化免费指南站：Claude Code、Codex、n8n 一站学

11 月 1 日更新的免费指南合集，每篇都从一个小任务讲到可验证的结果，附示例输入与排错：Claude Code 入门、Codex 与 Claude Code 路由分工、n8n 开源替代品、n8n 与 Zapier/Make 的计费对比等，免费可读、无需登录。

  2. 照着指南做完一个可检查的小任务（如一次小代码改动并验证）
  3. 再读计费对比篇，确认你的用量落在哪个工具的免费或低价档

来源：AI Automation Station

变现角度：把指南里的“小任务—可验证结果”结构抄到自己的教程产品里：可验证的交付感是付费教程与免费文章最大的区别。

8.9 个 Claude Skill：把 Claude 变成 9 个专岗助手

作者 11 月 1 日分享的 9 个 Skill：改写人味（humanizer）、头脑风暴、竞品画像、会议洞察、YouTube 转写、二阶思考、流程提效（kaizen）、发布规划、五岁小孩讲明白（eli5）。安装方式是下载 SKILL.md 后在 Claude 里上传，Claude 只在任务需要时加载对应 Skill。

3 步上手：
  1. 下载你最常用的 2–3 个 Skill 的 SKILL.md 文件
  2. 在 Claude 设置里上传，任务中直接提 Skill 名或让 Claude 按需调用
  3. 连续用一周，记录哪个 Skill 真正省了时间，删掉没用上的

来源：LinkedIn（Yonathan Levy）

变现角度：Skill 包是轻量产品形态：把某个行业的检查清单、话术、审稿标准写成 Skill 包卖给从业者，一次编写、处处复用。

9.X 挖矿｜孙可可：把线下培训拆成低价引流品 + 私域高价承接

孙可可分享的变现模式：把线下培训课拆解成低价引流产品先获客，再用私域里的一对一或小班定制服务承接高价转化。低价品解决信任问题，高价服务解决利润问题，两段分工明确。

3 步上手：
  1. 把你已有的培训或经验拆出一小块，做成低价引流品
  2. 引流品只解决一个具体问题，结尾自然衔接到一对一或小班服务
  3. 私域承接时按效果与定制程度定价，不与引流品同价竞争

来源：X @Sunkeke_AI

变现角度：有课、有经验的人可以直接抄这套两段式：低价品换流量与信任，高价定制换利润，比单卖一门课更稳。

Hailey 发起的 0 元挑战教程：用 Grok、Seedance 与 Midjourney 等工具做 3D 动漫 MV，涵盖生成、剪辑、配音与后期全流程。重点是“0 元”——全程用免费额度与免费工具链跑通。

3 步上手：
  1. 按教程选一首短音乐，定好动漫风格与分镜
  2. 依次跑生成、剪辑、配音、后期四步，先做出 30 秒成片
  3. 把成片发到短视频平台验证播放，再决定是否批量做系列

来源：X @HaileyAILabs

变现角度：3D 动漫 MV 是短视频平台的高完播品类：先做免费版验证流量，跑通后可接定制 MV、卖分镜模板或做账号矩阵。

11.X 挖矿｜Hailey：开源 Grok Bot 搭 AI 团队，一人组多角色班子

Hailey 介绍的开源版 Grok Bot 用法：兼容 Claude、Codex、Grok 与本地模型，一个人就能组建多角色 AI 团队分工干活，相当于把“团队”从招人变成配置角色。

3 步上手：
  1. 按教程部署开源 Grok Bot，接入你已有的一个模型
  2. 给不同角色定好分工（如调研、写作、审校各一个角色）
  3. 先让团队跑一个完整小任务，检查交接处是否丢信息

来源：X @HaileyAILabs

变现角度：“一人 AI 团队”是可卖的服务形态：帮小商家配一套多角色 Agent 班子，按月收维护费，比卖单次咨询更持续。

12.X 挖矿｜卡尔的 AI 沃茨：Personal Agent 时代的额度管理，别被降智

卡尔的 AI 沃茨讲 Personal Agent 时代的额度管理：把 ChatGPT 与 Codex 当作不同分工的同事，用额度管理避免降智与额度耗尽——不是所有任务都值得上最强的模型与最长的上下文。

3 步上手：
  1. 把你的日常任务分三档：简单查询、常规写作、深度推理
  2. 简单任务用便宜档，深度任务才上高档模型
  3. 每周看一次额度消耗，超支的任务类型降档或换流程

来源：X @aiwarts

变现角度：额度管理本身就是成本管理：帮团队做 Agent 用量审计与分流方案，按省下的订阅与 token 费分成，是 Agent 时代的新咨询品类。

13.X 挖矿｜想风转发的 100+ MCP 与 Skill 服务合集

想风转发整理的 AI 干货合集：100 多个 MCP 与 Skill 服务，覆盖搜索、AI 写作、AI 搜索等实用方向，适合一次性建立自己的工具箱，再按需取用。

3 步上手：
  1. 打开合集，先按你的工作流挑 5 个最相关的服务
  2. 逐个试一次，留下真正进日常流程的，删掉凑数的
  3. 把留下的服务写进你自己的 Skill 或 MCP 配置，形成固定工具箱

来源：X @xaiwind（转发整理）

变现角度：工具合集类内容本身就是流量品：整理、实测、筛选过的清单比原链接更有价值，可做成 newsletter 或付费资料包的引流品。
