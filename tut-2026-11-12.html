1.不用信用卡，也能用 Claude Code、Cline、n8n 和 Open WebUI：一個 OpenAI 相容金鑰走天下

教你用一個支援 OpenAI／Anthropic 格式的第三方 API 金鑰，同時接通 Claude Code、Cline、n8n 和 Open WebUI，不用綁國際信用卡。

3 步上手：
  1. 申請一個 OpenAI 相容的 API 金鑰（原文以 Ezkielyna 為例，最低充值 0.50 美元，支援 QRIS、USDT 或 Binance Pay），記下 Base URL 和金鑰。
  2. 在 Claude Code 設定 ANTHROPIC_BASE_URL（不帶 /v1，Claude Code 會自己補）及三個 DEFAULT_* 模型變數；Cline／Roo Code 選「OpenAI Compatible」供應商，填入.../v1 和模型 ID（如 deepseek-v4.1-flash）。
  3. n8n 在 Credentials → OpenAI 填入 API Key + Base URL，任何 OpenAI Chat Model 或 AI Agent 節點即可調用；Open WebUI 同樣填 Base URL 即可。

變現角度：大幅壓低 AI 開發與自動化接案的模型成本（不用月費訂閱、按量充值），適合接 n8n 自動化、AI 寫程式外包的小工作室。注意：本文作者即為文中網關的經營者，屬帶有推廣性質的實作教學，選用前宜自行比價同類 OpenAI 相容服務。

來源：DEV Community

2.用 n8n＋LangChain＋OpenRouter 打造可扛得住的 B2B 電郵行銷 CRM

把 B2B 開發信流程拆成 MailWriter（AI 寫信）與 Mailer（發送與業務邏輯）兩個解耦的 n8n 工作流，解決單體流程一壞全壞的問題。

3 步上手：
  1. 搭建 MailWriter 工作流：n8n 內用 LangChain 接 OpenRouter 上的 Claude，配合調校過的系統提示詞，把 AI 當成專業 B2B 文案。
  2. 搭建 Mailer 工作流：負責名單、發送節奏、退信與回覆處理等業務邏輯，與寫信流程分開部署。
  3. 接上乾淨的資料庫層做客戶與郵件狀態管理，並用 OpenRouter 的低成本路由把單封郵件生成成本壓到約 0.04–0.06 美元（來源原文數字）。

變現角度：做成「B2B 開發信代發／線索培育」服務賣給外貿與 SaaS 小公司，按月收費；單封成本不到 0.1 美元，定價空間大，也可打包成模板出售。

來源：DEV Community

3.Claude Fable 5.2 vs Opus 5.5：到底該用哪一個？

Anthropic 於 2026-11-09 發布 Claude Fable 5.2，本文對照 Opus 5.5 講清楚何時值得付兩倍價錢、何時不用。

3 步上手：
  1. 先升級 Claude Code 至 2.1.321 或更新版（claude update），再用 /model fable 切換。
  2. 日常工作（寫程式、修 bug、寫作、資料分析）留在預設的 Opus 5.5；只有大型多檔案改動、長時間自主任務、Opus 反覆修不好的 bug 才切 Fable 5.2。
  3. 在 /model 選單按 s 只切換當前 session，別按 Enter 設為全域預設，避免一直停在貴一倍的模型上。

變現角度：省成本即賺錢——Fable 5.2 定價為每百萬 tokens 輸入 8 美元／輸出 40 美元，正好是 Opus 5.5（4／20 美元）的兩倍（來源原文數字）；接案開發者按任務難度分流模型，可把 API 成本砍半而不損品質。

來源：DEV Community

7.如何寫出你自己的 Claude Skill（零程式基礎也行）

把重複交代給 Claude 的工作寫成一個 Skill，以後一句話就照你的規矩辦，整個 Skill 就是一個資料夾加一個 SKILL.md 檔案。

3 步上手：
  1. 找出你向 Claude 解釋過不只一次的工作（例如查核聲明、寫週報），把步驟與規則寫成 plain text。
  2. 建資料夾.claude/skills/<名字>/，裡面放 SKILL.md，頂部寫 name 與 description 兩行——description 是 Claude 判斷何時啟用它的關鍵觸發條件。
  3. 測試：用 /<名字> 呼叫它，或讓 Claude 在相關請求時自動啟用；最省事的方法是直接叫 Claude「把這個流程寫成 Skill」，再逐行校對。

變現角度：把高頻工作流程做成 Skill 庫自用省時間（省下的工時即利潤）；也可把成套 Skill 打包成付費模板賣給同行——文中提到 Anthropic 官方也隨附含 analyse、build dashboard 等技能的資料技能包，屬同類產品形態。

來源：Mstimaj

8.Gemini 4 Carbon vs Argon：慢一點的 Carbon 什麼時候反而划算？

實測對比 Google 兩款新模型：Carbon 擅長難查核的重活、Argon 適合即時互動，附 Artificial Analysis 評測分數與真實 token 成本對照。

3 步上手：
  1. 按任務分流：寫程式代理、根因除錯、長文件精確分析用 gemini-4-carbon；日常開發、互動式寫程式、SaaS 自動化用 gemini-4-argon。
  2. Carbon 保持預設 thinking_level: medium，max_output_tokens 至少設 32,768，HTTP timeout 至少 15 分鐘；high 只在輸出預算夠大時用。
  3. 記住價格窗口：兩款模型到 11 月 30 日前同價為每百萬 tokens 輸入 2 美元／輸出 10 美元，12 月 1 日起漲為 4／20 美元（來源原文數字），重活盡量在 11 月底前跑完。

變現角度：模型選型直接決定接案利潤——評測數據顯示 Carbon 在 Artificial Analysis Intelligence Index v5.0.1（截至 2026-11-11）High 檔得分 60 分對 Argon 的 50 分，困難任務上 Carbon High 每任務成本反而比 Argon High 低 22%（評測機構數據）；但簡單任務 Carbon 預設檔會多寫 3.8 倍輸出 tokens、貴 3.05 倍、慢 2.75 倍（作者實測），用錯模型等於燒錢。

來源：老張的部落格
