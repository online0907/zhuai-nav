教程速递｜2026-11-01：12 篇 AI 干货教程

1.Claude Code 长任务不用守屏：用 Skill 让家里音箱播报进度

作者把长时任务交给 Claude Code 后不想守在屏幕前，于是做了一个 Skill：任务开始与完成时通过 Home Assistant 让 Echo 音箱播报。踩过的坑包括 Alexa 的 _speak 接口实际已静默、/tmp 重启会丢脚本，改用 _announce 并把脚本放持久目录才跑通。

3 步上手：
  1. 建一个 alexa-report Skill 文件夹，写清触发条件与播报文案
  2. 经 Home Assistant 的 SSH 插件调用持久目录下的播报脚本，用 _announce 而不用 _speak
  3. 先跑一个“改文件—等 CI—提 PR”的长任务验证播报，再把 Skill 交给日常任务复用

来源：DEV 教程

变现角度：长任务托管、夜间跑批、代跑 Agent 都是可卖的服务：客户不关心你守没守屏，只关心进度可查、出错可报，把“播报进度”做成托管服务的标配功能。

2.从零写第一个 Claude Skill：代码评审 Skill 全流程

这篇分步指南以代码评审 Skill 为例，讲清 Skill 的结构：文件夹名即命令名，SKILL.md 由 YAML frontmatter（name 不超 64 字符、description 不超 200 字符）加正文指令组成，长参考资料放同目录单独文件、按需加载。

3 步上手：
  1. 建 code-review 文件夹与 SKILL.md，description 写触发场景而非口号
  2. 正文写清何时用、按什么标准、输出什么格式，需要确定性结果的步骤配 scripts 脚本
  3. 两种方式测试：触发场景下是否自动加载、直接用 /code-review 调用，再与禁用 Skill 的输出对比

来源：DEV 教程

变现角度：把团队的代码规范、审稿清单、发版检查写成 Skill 包卖给小团队：一次编写、处处复用，按“帮团队省多少返工”定价，比卖单次咨询更可持续。

3.做一个 20 分钟能交付的 Claude Skill：脚本、打包与沙箱规则

这篇指南把 Skill 拆成三层：frontmatter 元数据先读、正文按需加载、配套文件只有正文点名才打开。关键提醒是 Skill 里不要放 API 密钥，脚本在 Claude 沙箱里只有 Python 标准库、没有本机网络与已装包，测试时要先在本地跑通同样的输出。

3 步上手：
  1. 确认 Claude 设置里有 Skills 入口，再建技能文件夹与 SKILL.md
  2. 需要确定性结果的步骤写成 scripts/check.py，先本地跑通、再按沙箱规则复核
  3. 打包成 ZIP 时让 SKILL.md 位于压缩包根目录，上传后用触发场景实测一次

来源：AI Release 指南

变现角度：Skill 打包交付是轻量产品形态：给客户一个 ZIP 加一份触发清单，就能按“一个可复用工作流”收费，不用为每个客户重写提示词。

4.n8n 自动写 Upwork 提案：一份职位描述出三件套

这篇免费 n8n 工作流教程用 AI Agent 分析职位描述，再调用三个子工作流分别生成 Upwork 申请文案、Google Docs 项目提案与 Mermaid 技术架构图。注意主工作流只含引用，三个子工作流需另外导入或自建。

3 步上手：
  1. 下载主工作流 JSON 导入 n8n，接好 OpenAI 聊天模型节点
  2. 另外导入或搭建三个子工作流：生成 Mermaid 代码、生成 Docs 提案、生成申请文案
  3. 投一份真实职位描述跑通全链路，确认三件产出都生成再接客户单

来源：Medium 教程

变现角度：自由职业者接单最费时的就是写提案：把这套流程做成“提案代写包”按单收费，或卖给接单者当提效工具，省下的时间就是你的定价依据。

5.n8n 内容日历 Agent：一个主题变两周邮件与社媒排期

这篇免费教程用 n8n 搭建内容日历 Agent：聊天触发后输入一个 campaign 主题，Agent 规划两周的邮件与社媒内容，全部写入 Google Sheet 供人工审核，全程约 12 分钟、72 步分 12 节，模型建议用便宜的 GPT-5 mini 起步。

3 步上手：
  1. 在 n8n 新建工作流：聊天触发器接 AI Agent 节点
  2. 给 Agent 配聊天模型与记忆，再接 Google Sheets 工具并建好表头
  3. 输入一个真实主题跑一遍，检查两周排期是否都落表、再人工改一版再发

来源：Ynteractive 免费教程

变现角度：内容排期是中小商家每月都付钱的活：按月提供“主题进、排期表出”的托管服务，比卖单篇文案更稳，Sheet 就是客户看得见的交付物。

6.n8n 线索跟进：表单进表、AI 回复只生成草稿不直发

这篇初学者教程验证过一次真实运行：表单收线索先写 Google Sheet，再准备回复并生成 Gmail 草稿，人工确认前不直发。作者的实测执行编号 2689，全程 5.076 秒完成，刻意用模板回复而非 AI 直发，保证可预测、可检查。

3 步上手：
  1. 用 n8n 表单触发器收线索，第一步先写入 Google Sheet 留底
  2. 用模板字段拼回复（带上线索自己的信息），再生成 Gmail 草稿
  3. 跑一次测试提交，核对表格行与草稿都对，再决定是否升级为 AI 写回复

来源：Ai Spark 教程

变现角度：线索跟进是本地商家愿意付月费的刚需：先卖“不丢单”这个结果，表单加表格加草稿三件套就能开张，后续再加 AI 回复升级收费。

7.n8n 接本地 Ollama：Docker 同网段，AI 步骤零 token 费

这篇指南讲清最常见的坑：容器里的 localhost 指的是容器自己，不是宿主机，所以 n8n 的 Ollama 凭据要填 http://ollama:11434。示例工作流每小时读 RSS，用本地模型摘要后推到 webhook，数据不出本机。

3 步上手：
  1. 用 Docker Compose 把 n8n 与 Ollama 放同一网络，拉一个 Llama 3.2 3B 模型
  2. 在 n8n 建 Ollama 凭据，Base URL 填 http://ollama:11434
  3. 搭定时触发加 RSS 读取加 Basic LLM Chain 的摘要流，跑一小时验证摘要准不准

来源：BullQuill 教程

变现角度：本地模型加自动化是隐私敏感客户的卖点：律所、诊所、中小企业内训资料摘要，按“数据不出域”报价，token 零成本就是你的毛利。

8.Reddit 上 5 个 AI 副业实测复盘：先看平台规则再动手

作者梳理数百条 Reddit 帖子后，挑出 5 个经真实用户测试的 AI 副业模型，并逐一核对工作流、平台规则与残酷现实：很多看起来“被动收入”的玩法，实际是技术活或引流活，先看规则再投入时间。

3 步上手：
  1. 在 r/sidehustle 与 r/passive_income 按月度热门帖筛出带真实结果的案例
  2. 逐个核对平台规则与所需工具，把“能做”与“能持续赚钱”分开记
  3. 只选一个模型做 2 周小规模实测，有收入或有客户反馈再加投入

来源：AICap 复盘

变现角度：副业选题本身就能做成内容产品：把“实测复盘”写成系列，附工具清单与避坑点，靠教程引流再卖模板或咨询，比直接抄一个副业更稳。

9.零预算发布副业：6 周波次打法，别指望一天爆

这篇 2026 年 10 月更新的发布指南指出，免费发布如今 cost 的是时间、链接或互动：按 Show HN、r/SideProject、Peerlist、DevHunt、Indie Hackers、Product Hunt 的顺序排成 6 周波次，每站只看点击与注册，不看点赞数。

3 步上手：
  1. 先做一个无需注册可试用的演示，Show HN 只接受可试用的东西
  2. 按 6 周顺序逐站发布，每站发前先读当天的版规，同一文案不要一小时内连发五站
  3. 每站记录访客与注册数，点赞高但零注册的渠道下一轮降优先级

来源：Traffiklist 指南

变现角度：发布执行本身就是服务：很多独立开发者缺的不是产品，是发布节奏，把 6 周波次做成代发布包，按“上线渠道数加注册数”收费。

10.GitHub 10 月热榜风向：Agent 工作流成主线，明星项目看周增

这篇 10 月 19 日的热榜分析提醒：星数只是注意力，不是装机量与付费客户。当周 VoiceStudio 与 ArtCraft 各增约 1.6 万星，HyperFrames、AI 求职、Context Mode 也在前列，说明 Agent 相关项目仍是热榜主线。

3 步上手：
  1. 每周固定看一次 GitHub Trending 的周增星数，别只看累计星数
  2. 把上榜项目按“能解决什么具体任务”分类，挑一个与你业务相关的跑通
  3. 跑通后写一篇实测笔记，附你的使用场景与成本，沉淀为选题库

来源：Anchor Terminal 分析

变现角度：热榜追踪可以做成周报产品：每周挑 3 个可落地的项目给读者，附上手成本与变现点，靠稳定更新积累订阅或社群。

11.10 月 GitHub AI 趋势：从追模型转向 Agent 基建与记忆层

这篇 10 月 21 日的趋势盘点指出，个人 Agent、编程助手、记忆层是三条主线：OpenClaw、Hermes Agent、OpenCode、Codex、Gemini CLI、claude-mem、Mem0、Letta 各自卡位，许可证分化（AutoGPT、n8n 的部分限制）开始影响商用选型。

  2. 商用前先查许可证：核心开源不等于全部可商用，平台目录可能另有限制
  3. 把记忆层单独拎出来做一次跨会话测试，断点续跑不断档才算可用

来源：ClawdBytes 趋势盘点

变现角度：Agent 基建选型咨询正在涨价：帮团队在许可证、记忆层、编程助手之间做一次选型并落地，比单纯推荐一个工具更值钱。

12.两个高星仓库看 Agent 成熟：开源编程 Agent 与 AI 机构

这篇热榜解读对比两个仓库：OpenCode 约 21.94 万星、2.93 万 fork，是终端编程 Agent 的基础设施形态；agency-agents 约 16.27 万星、2.62 万 fork，把数百个专业 Agent 人格按工程、设计、销售、市场等部门组织起来，可装进 Claude Code、Cursor、Codex 等十余种工具。

3 步上手：
  1. 先装 OpenCode 跑一个多步骤任务，确认它在你的系统上能稳定跑完
  2. 再按需引入 agency-agents 的某一部门人格，别一次性全量启用
  3. 把“任务分工表”写成团队模板：谁负责、谁复核、谁上线，分工不清的 Agent 只会更快出错

来源：CoddyKit 热榜解读

变现角度：把“AI 机构”思路卖给小团队：不是卖工具，而是卖一套分工与复核流程，帮客户把 Agent 从玩具变成可交接的生产力。
