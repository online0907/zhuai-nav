1.llm.asm：用純 x86-64 匯編寫一個大模型，12KB 跑起 Qwen3-0.6B 推理

本週 GitHub 新星：alesha-pro/llm.asm 用 100% 純 x86-64 NASM 匯編寫了一個大模型項目，含 Qwen3-0.6B 推理（12KB）、可啟動的裸機操作系統（22KB）與從零寫的 Mini-GPT 訓練器（32KB），零 C、零 libc、零依賴，MIT 協議，本週已漲 1651 星。變現角度：底層推理、手寫高性能代碼是最難被 AI 替代的手藝；看懂這套實現，就能接推理優化、端側部署這類高單價技術單。

來源：GitHub · alesha-pro/llm.asm

3 步上手：
  1. 克隆倉庫按 README 裝好 NASM，先跑通 Qwen3-0.6B 推理示例，確認能在本機出結果。
  2. 對照 Mini-GPT 訓練器代碼，把前向、反向、採樣三段逐段讀懂，改超參跑一次自己的小訓練。
  3. 把「匯編級推理優化」寫進作品集，接端側模型部署、推理加速的諮詢或外包單。

2.openset-llm：普通 CPU 就能跑大模型，8GB 內存、不用顯卡

openset-llm 是一個跑在普通 CPU 上的大模型推理引擎，8GB 內存就能用，不需要 GPU 加速，本週漲 199 星、總星 1.7K。變現角度：幫小公司、個人把閒置電腦變成離線 AI 工作站，是現成的本地部署服務；不懂買卡的客戶最願意為「不用買顯卡」付費。

來源：GitHub · opensetlabs/openset-llm

3 步上手：
  1. 按 README 下載對應平台的二進制或編譯，先載入一個小模型驗證能出字。
  2. 對照官方示例測長上下文與速度，記下不同模型在自己機器上的 token／秒。
  3. 打包成「舊電腦變 AI 工作站」服務：上門或遠程幫客戶裝好、配好模型，按次收費。

3.OpenGame：用 AI 智能體做遊戲，一鍵發到微信、抖音、TikTok

OpenGame 是開源遊戲開發平台，讓用戶用 AI 智能體創建並發布 3D 與小遊戲，可發到微信、抖音、TikTok 等多平台，本週漲 199 星、總星 822。變現角度：小遊戲最吃量和速度——AI 做遊戲＋多平台分發，適合接小遊戲定製單或自己做爆款小遊戲吃廣告分成。

來源：GitHub · nexu-io/opengame

3 步上手：
  1. 按 README 部署 OpenGame，先用示例模板生成一個最小可玩遊戲並跑通發布流程。
  2. 換主題讓智能體生成第二款遊戲，記錄哪類提示詞出品質量最穩。
  3. 拿兩款成品去談小遊戲定製客戶，或自己上架吃平台廣告分成。

4.PiBot：本地優先的 AI 智能體團隊，桌面端多智能體群聊

PiBot 是開源、本地優先的桌面 AI 智能體團隊：多智能體群聊、電腦操作、瀏覽器、MCP、定時任務與審批，支持 macOS、Windows、Linux 與 Android，基於 pi 構建，本週新上榜已漲 659 星。變現角度：本地 Agent 是眼下最熱的創業方向——會搭這套，就能幫小團隊做「不出內網的 AI 助手」部署，按項目收費。

來源：GitHub · w01fb0ss/PiBot

3 步上手：
  1. 按 README 在桌面端裝好 PiBot，先建一個雙智能體群聊，驗證任務分工與審批流程能跑通。
  2. 接一個 MCP 工具（如文件、日曆），讓智能體真正動手做一件日常任務。
  3. 整理一份「本地 Agent 部署清單」，去談對數據不出內網有要求的中小客戶。

5.pop-agent：給編程智能體裝一個本地 Web 界面，推理中途可打斷糾正

PopAgent 是編程智能體的本地 Web 界面：看推理過程實時流動，中途可打斷糾正、管理模型與工具，支持 pi、Codex、Claude Code、OpenCode 與 DSH，會話全留在本地，本週新上榜 130 星。變現角度：會用這類工具接單的人，交付速度比純手寫快數倍；把「AI 編程＋人工把關」做成服務，就是現在最實在的接單模式。

來源：GitHub · duzhenxun/pop-agent

3 步上手：
  1. 按 README 啟動 pop-agent，接上你常用的編程智能體，先跑一個小改動驗證中途打斷糾正好用。
  2. 用它完整交付一個小需求，記錄從需求到驗收的全流程耗時。
  3. 把流程沉澱成報價模板，去接「小步快跑、按次收費」的開發單。

6.flyx：50MB 的本地推理引擎，零依賴、原生長上下文

flyx 是零依賴的本地大模型推理引擎，整個二進制約 50MB，原生長上下文、按 GPU 調優、內置推測解碼與 Web 儀表盤，本週新上榜 73 星。變現角度：輕量推理引擎是端側 AI 產品的地基——會用它，就能把大模型塞進別人意想不到的硬件裡賣方案。

來源：GitHub · enwove/flyx

3 步上手：
  1. 下載對應平台的 flyx 二進制，按 README 載入模型，先在儀表盤上跑通一次對話。
  2. 測一組長上下文任務，對比開啟推測解碼前後的速度差異。
  3. 挑一個場景（如離線客服、本地文檔問答）做成可演示的最小產品，拿去談客戶。

7.awesome-free-search-apis：給不能聯網的 AI 配免費搜索接口

一份手工驗證過的免費搜索／抓取／嵌入 API 清單：給不能聯網搜索的 AI 配搜索、抓取與嵌入接口，每個額度都經過人工認領驗證，可直接接進自己的智能體或項目，本週新上榜。變現角度：做 Agent 的人都卡在「模型不會上網」這一步——整理好免費額度清單，本身就能做成付費資料包或接「給 Agent 接聯網能力」的單。

來源：GitHub · waw666waw666/awesome-free-search-apis

3 步上手：
  1. 按清單挑 2–3 個免費搜索 API，先在自己的智能體裡接通，驗證額度與返回質量。
  2. 把「搜索→抓取→嵌入」串成一條最小管線，跑通一個真實查詢任務。
  3. 整理成部署文檔，接「給現有 Agent 加聯網搜索」的改造單。

9.n8n＋Claude Code：做「交付後還能穩定跑」的 AI 智能體，自由職業者才有回頭客

Freelancing Network 11 月 22 日指南：交付後還能穩定跑的 AI 智能體，才能帶來回頭客。核心方法是先列出故障模式（缺 API Key、限流、空返回、下游出錯），再在 n8n 裡給主路徑加錯誤分支（try-continue-alert 循環），失敗項寫表＋發提醒；Claude Code 只負責判斷，輸出後用節點驗證。變現角度：把「異常處理、日誌、監控」單獨列成報價項，再推每月監控＋1 小時修復的 retainer，收入比一次性交付穩得多。

來源：Freelancing Network

3 步上手：
  1. 下一個智能體項目先寫故障清單，再搭主路徑，每個關鍵節點後加錯誤分支。
  2. 用三套數據測試：乾淨數據、缺字段數據、觸發限流的數據，確認失敗時有提醒、不靜默。
  3. 把異常處理與監控寫進報價單，交付時主推月度 retainer。
