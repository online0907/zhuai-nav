教程速遞｜2026-11-21

2026-11-21 · 猪猪侠玩AI · 每天更新 12 篇

1.用 Claude + Google Sheets 自動給賬單分類，42 筆賬幾秒鐘分完

Make 監聽表格新增行，Claude 按商家和描述自動歸類，分類結果寫回同一行。演示用的 42 筆虛擬支出、共 $486.70，幾秒鐘全部歸類完畢（12 筆餐飲、9 筆交通、11 筆軟件、10 筆辦公，數字來自原文）。

來源：DEV（2026-11-21）

3 步上手：
  1. 在 Google Sheets 建支出表，加一列 Category，表頭寫好 4 個分類（Food & Drink、Transport、Software、Office）。
  2. 在 Make 建場景，觸發器設為「表格新增行」，把商家和描述發給 Claude，提示詞要求只返回 JSON 且只能用列表內的分類。
  3. 把 Claude 返回的 category 映射回同一行的 Category 列，先用虛擬支出測試，跑通後再接真實賬單。

變現角度：做成「小微企業記賬自動化」代運營服務，按月收費；或把這套流程打包成模板/教程賣給自由職業者和個體戶，幫他們省下每月手動對賬的時間。注意原文提醒：描述含糊的商家可能分錯類，要留人工覆核一步，不能聲稱可替代會計。

2.用 4 個 Grok Bot 搭一個網頁設計工作室：獲客、建站、運維全自動

作者把 Grok Bot 按 Growth（獲客）、Builder（建站）、Ops（運維）、Content（內容）四人分工，每個 Bot 有固定職責和定時任務，人只負責審批發送、上線和 DNS，客戶站統一托管在 Novence。

來源：DEV（2026-11-21）

3 步上手：
  1. 給 4 個 Bot 寫好角色指令並設好「先問後發」規則：Growth 只起草不發送，Builder 不碰線上域名 DNS，Ops 不直接給客戶發郵件。
  2. 接入 Novence 的 MCP（api.novence.ai/mcp）或 CLI（npx novence deploy ./dist），讓 Builder 能一鍵發預覽站。
  3. 把 Growth 的找客戶流程存為定時任務：每個工作日早上 9 點搜本地商家、挑 5 家網站問題最明顯的、起草 80 詞以內的 outreach 郵件等你審批。

變現角度：一人工作室接本地小商家建站單：Bot 負責找客戶和日常運維，人只做談單和終審，邊際成本低；每月運維報告還能做成固定月費服務。原文明確說數字均為示例、未編造成交數據。

3.別再寫巨型提示詞了：把一個 Agent 拆成「解析—路由—執行」三層

單個提示詞膨脹到幾千 token 後約 20% 的情況會幻覺、漏指令，正確做法是按微服務思路拆成多 Agent：解析器抽實體、路由器分流、執行器只幹一件事，附 Python + Pydantic 可跑的示例代碼。

來源：DEV（2026-11-21）

3 步上手：
  1. 用 Pydantic 定義路由輸出結構（分類、優先級、抽取的實體，如賬單號 INV-9402）。
  2. 寫一個只做分類的 Router Agent，再按 SUPPORT/BILLING/TECHNICAL 各寫一個只接已驗證輸入的 Executor。
  3. 簡單解析任務用 GPT-4o-mini 這類輕量模型，複雜邏輯再上大模型，調試時只改出問題的那一層。

變現角度：這是能直接賣給中小企業的技能：把客戶現有的客服/工單流程按這套模式重構成多 Agent 系統，按項目收費；或做成企業內訓課，幫團隊把已有 Agent 的出錯率降下來。

4.讓 AI 編程助手少翻車的 5 個概念：上下文、計劃、驗證循環、規則文件、MCP

Uber 的 AI 工程師總結：Agent 忘事、瞎改代碼、謊稱做完，根源不在模型，而在 5 個沒搭好的概念——任務拆小管上下文、先計劃後寫碼、生成—測試—覆核循環、把規則寫進 CLAUDE.md、用 MCP 接真實工具。

來源：DEV（2026-11-20）

3 步上手：
  1. 把大任務拆成里程碑，關鍵決策寫進項目文檔，別指望聊天記錄能記住。
  2. 讓 Agent 先出計劃（改哪些文件、有什麼風險），你審過計劃再讓它動手。
  3. 在項目根目錄放一份規則文件（如 CLAUDE.md），寫清測試怎麼跑、哪些配置絕不能碰，每次會話自動生效。

變現角度：接 AI 編程輔導/代碼審查單：很多新手不是缺工具，而是缺這套工作流，幫客戶搭好一次就能收諮詢費；也可以把這 5 條做成檢查清單，打包進自己的 vibe coding 接單服務裡，減少返工就是直接省錢。

5.HyperFrames：開源免費的 AI 視頻編輯器，寫 HTML 就能出可逐幀改的 MP4

HeyGen 開源的視頻框架，把視頻寫成 HTML + CSS 動畫，用 FFmpeg 渲染成 MP4，生成結果是真實工程文件而不是一次性成片，哪裡不滿意改哪一行再渲染；GitHub 87,702 stars，Apache 2.0 協議，本週熱榜。

來源：GitHub（2026-11-21 當周熱榜）

3 步上手：
  1. 裝 Node.js 22+ 和 FFmpeg，跑 npx hyperframes init my-video 建項目。
  2. 讓 Claude Code / Cursor 等編程助手裝上 HyperFrames 技能（npx hyperframes skills update），一句話描述要做的視頻，如「10 秒產品介紹，標題淡入+背景音樂」。
  3. npx hyperframes preview 在瀏覽器裡看效果，滿意後 npx hyperframes render 出 MP4；內置約 450 個現成組件（轉場、字幕、動效圖表等）先查再手寫。

變現角度：批量做產品介紹、數據可視化、社媒短視頻接單：一次搭好模板後換文案就能出新片，邊際成本接近零；免費版就能用，Pro 才加 HeyGen 的頂級音視頻模型，起步不用花錢。

6.FreeLLMAPI：把 87 家免費大模型額度拼成一個統一接口，每月約 101 億 token

自托管的路由器，把 Google、Groq、Cerebras、Mistral 等 87 家免費額度（項目自述：1,313 個免費模型端點、約 101 億 token/月）聚合成一個 OpenAI 兼容接口，自動選最優模型、被限流自動切換，Claude Code、Cursor、Gemini CLI 都能直接接。

來源：GitHub，55,966 stars（2026-11-21 當周熱榜；數字為項目自述口徑）

3 步上手：
  1. 一條命令裝好（curl -fsSL https://freellmapi.co/install.sh | bash，需 Docker），打開 http://localhost:3001。
  2. 在 Keys 頁把各家免費 API Key 加進去，排好 Fallback Chain，拿到統一的 freellmapi-… 密鑰。
  3. 用 npx freellmapi setup-claude --url http://localhost:3001 --api-key <統一密鑰> 一鍵把 Claude Code 等工具指過去，之後所有調用都走免費池。

變現角度：直接省成本：個人開發、寫 Agent、跑自動化腳本的模型調用費可以壓到接近零；注意項目 README 明確寫著「僅供個人實驗」，且免費版模型目錄是月度快照（新模型晚 30 天），別拿去包裝成商業 API 轉賣。

7.Intel OpenVINO：沒有顯卡也能本地跑 AI 模型，11 月 21 日 GitHub 日榜第 8

Intel 的開源推理工具包，把 PyTorch、TensorFlow、ONNX 等模型轉成優化格式，在普通 CPU、Intel GPU/NPU 上跑，附帶 LLM 聊天機器人、YOLOv11、Whisper 語音識別等官方示例 Notebook；11 月 21 日 GitHub 日榜第 8，當天新增 217 stars，總計約 11,873 stars（榜單數據口徑）。

來源：GitHub，Apache 2.0

3 步上手：
  1. pip install -U openvino，import openvino as ov 驗證安裝。
  2. 用 ov.convert_model() 把現有模型（如 torchvision 的 ShuffleNet）轉成 OpenVINO 格式，再 core.compile_model(ov_model, 'CPU') 編譯到 CPU 上跑推理。
  3. 照官方 Notebook 跑一個完整例子（LLM 聊天機器人或 Whisper 轉寫），再按需換成自己的模型和場景。

變現角度：幫小商家把 AI 功能部署到現有電腦上，不用買顯卡、不用按量付雲端推理費，一次性收部署費；尤其適合本地化要求高的場景（數據不出內網），是「低成本 AI 落地」接單的好賣點。

8.GPT-6.2 純代碼造了一座宮崎駿風格 3D 夢幻小鎮《風眠鎮》

Hailey 用 GPT-6.2 純代碼打造了一座宮崎駿風格的 3D 夢幻小鎮《風眠鎮》：從建築、花草、江水到光影，前前後後打磨了整整 7 個版本。最難的不是把場景搭出來，而是讓每個角落都足夠精緻、自然，讓整座小鎮看起來真的有生活氣息。同系列還有 GPT-6.2 Sol 造的東方巨龍：數萬片獨立鱗甲、動態龍鬚和鬃毛、雲海山峰加 60 秒電影級飛行運鏡，全部在瀏覽器裡即時渲染。

來源：X @HaileyAILabs（2026-11-20/21）

3 步上手：
  1. 用 GPT-6.2 生成 Three.js 場景骨架，先讓整體結構在瀏覽器跑起來。

變現角度：接 3D 場景、品牌視覺、互動網頁訂單——純代碼出片的成本遠低於建模外包；把「提示詞—迭代—出片」流程做成課程或模板包也能賣。
