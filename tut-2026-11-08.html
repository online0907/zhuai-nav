4.點樣由零寫一個 Agent Skill（Flavio Copes，11 月 8 號）

作者有 46 個自用 Skill，今次實戰由零寫一個 release-readiness Skill，仲要真係測試邊啲提示會觸發、邊啲唔會。關鍵心法：觸發全靠 SKILL.md 嘅 description 寫得準唔準。

來源：Flavio Copes

3 步上手：
  1. 用 SKILL.md 格式（YAML frontmatter＋Markdown）寫好 name 同 description，觸發全靠 description 寫得準
  2. 個人 Skill 放 ~/.claude/skills/
  3. 用 skills-ref validate 驗證，再用 claude -p 做啟用測試

變現角度：將重複工作流程寫成 Skill 賣／分享（作者寫作 Skill 三星期內被調用 139 次），或用 Skill 幫客戶將發佈、測試流程標準化收費。

8.將爛咗嘅 UI 截圖掟入 Claude Code，再用 Playwright 證明修好咗

實戰教學：截圖＋失敗測試＋像素對比，三步令 Agent 唔可以「話修好就算」。先用 Playwright 截低出事畫面，寫一個針對呢個 bug 會失敗嘅測試，再將截圖貼入 Claude Code 修，修好後再由 Playwright 截圖對比驗證。

來源：DEV

3 步上手：
  1. 用 Playwright 截低出事畫面
  2. 寫一個針對呢個 bug 會失敗嘅測試
  3. 將截圖貼入 Claude Code（Ctrl+V），叫佢修好後再由 Playwright 截圖對比驗證

變現角度：呢個「截圖＋自動驗證」流程可以直接賣畀接案客戶做 UI QA 服務，按次收費。

卡爾的AI沃茨花兩日實測 GPT Image 2.6，核心更新有三點：原生 GIF 支援、角色一致性大幅提升、連續編輯能力更強。以前做連續動作 GIF 要將提示語寫得非常具體，而家一句「保持角色一致，換個動作」就得，連續出圖角色唔會崩。十大玩法包括黏土手辦、扁平風貼紙、像素風貼紙、一鍵出片、賽博朋克風、3D 盲盒手辦、手繪鉛筆素描、角色融合、皮克斯風格，以及令動圖「動起來」。
