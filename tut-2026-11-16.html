教程速遞｜2026-11-16

2026-11-16 · 猪猪侠玩AI · 共 21 篇，每篇附上手步驟和變現角度

1.OpenMausBot：開源版 Grok Bot，每個對話都是一個本地 Agent

受 xAI Grok Bot 啟發的開源項目：一個聊天 App 裡每個對話都是一個真實 Agent——Claude、Codex 或 Grok 在本地運行，各有自己的性格、模型、雲電腦與已連接應用。關鍵區別是開源、跑在你自己的機器上、用你自己的登錄，不用買昂貴的訂閱。11 月 8 日當週熱榜單日新增 1,437 星、總星數 18,073。每個機械人走本地安裝的 CLI（claude、codex、grok），對話記錄、密鑰與事件都存在 ~/.openmausbot，不上雲；支援 500+ 應用（經 Composio）與雲電腦（經 Boat）。

3 步上手：
  1. 按倉庫 README 安裝 OpenMausBot，確認本地已裝好 claude／codex／grok 其中一個 CLI。
  2. 新建一個對話，給它一個人設和任務（例如「幫我每天整理郵件」），跑通一次完整對話。
  3. 把跑通的人設存下來，下次同類任務直接複用，不用重複交代。

變現角度：「一人多 Agent」是最直觀的代運營賣點：幫客戶把重複工作拆成幾個專職 Agent（客服、整理、跟進），按月收維護費；開源＋本地運行還能打「數據不出客戶電腦」的隱私牌，比雲端訂閱更容易談下對數據敏感的中小企業客戶。

來源：GitHub milind-soni/OpenMausBot

2.billion-context：給 Agent 的上下文壓縮代理，萬次調用不爆上下文

一個坐在 Agent 與模型 API 之間的代理：用增量壓縮重寫 Anthropic／OpenAI 的數據流，由模型自己決定何時、壓縮什麼內容成高保真摘要，而不是硬截斷。實測在 204,800 token 的窗口裡可持續數千次調用（最高 12,000+ 次），單次調用平均約 126K token，累計峰值約 15.2 億 token；壓縮成本不超過 2%，健康會話的前綴緩存命中率保持在 95–97%。11 月 8 日當週熱榜項目，總星數 5,048。

3 步上手：
  1. 克隆 ranxianglei/billion-context，讀 README 確認它支援你的模型供應商。
  2. 先在一個長會話任務上試跑，對比開與不開代理時的 token 消耗。
  3. 把壓縮策略（compress／search_context 等四個工具）寫進你的 Agent 配置，讓長任務自動走壓縮。

變現角度：長會話 Agent 最大的隱形成本是 token：上下文一爆，要麼重開會話丟失進度，要麼付天價 token 費。能幫客戶把長任務的 token 賬單砍下來、又不丟上下文的部署服務，本身就能收費；做 Agent 代運營時，這也是「同樣效果、一半成本」的競價賣點。

來源：GitHub ranxianglei/billion-context

3.NVKE：NVIDIA GPU 數據中心的 Kubernetes 管理層

NVIDIA DSX AI Factory 的開源項目（Go 語言）：讓 GPU 數據中心運營方能像雲廠商一樣，把 Kubernetes 作為託管服務提供給客戶。每個工作負載集群有自己獨立的控制平面、etcd 與節點池；通過 NICo（NVIDIA Infra Controller）經 API 管理裸金屬服務器，GPU Operator 自動裝驅動、容器工具包與設備插件。定位相當於「開源 GPU 版的 AWS EKS」，Apache 2.0 許可；目前屬預覽版，官方暫不建議生產環境使用，系統亦不具備自我更新與自動擴縮容能力。

3 步上手：
  1. 讀倉庫 README 的架構圖，搞清管理平面與工作負載集群的分工。
  2. 在測試環境按文檔部署一個最小集群，確認能經 kubectl 訪問。
  3. 對比你現有的 GPU 租賃或雲端方案，算一筆自建託管的成本賬。

變現角度：GPU 算力租賃是實打實的生意：手上有顯卡資源的人，可以用這套開源方案把「裸卡」包裝成「託管 Kubernetes 服務」出租，收的是服務費而不只是電費；即使不做租賃，懂這套架構也能接 GPU 集群的部署與運維單子，客單價遠高於普通網站部署。

來源：GitHub dsx-ai-factory/nvke

4.Astryx：Meta 開源的設計系統，150+ 無障礙組件

Meta 內部用了八年的開源設計系統，支撐 13,000+ 個應用，是該公司使用最廣、規模最大的設計系統。150+ 無障礙組件、品牌級主題、深色模式與 CLI，基於 React 19+ 與 StyleX。最特別的一點：人類與 AI 助手用同一套工具搭建界面——這意味著 Agent 生成的界面可以直接複用這套組件，設計與代碼不再各說各話。11 月 8 日當週熱榜單日新增 863 星、總星數 16,250。

3 步上手：
  1. 克隆 meta/astryx，按 README 跑起示例項目，看一遍組件清單。
  2. 挑一個你常做的頁面類型（落地頁、儀表板、表單），用 Astryx 組件重搭一次。
  3. 把常用組件組合存成模板，下次讓 Agent 生成界面時直接指定用這套組件。

變現角度：接「幫客戶做網站／做產品界面」的單子時，最大成本是反覆改設計稿；一套現成、無障礙合規的組件庫能把交付時間壓下來，報價可以按「天」而不是按「週」算。更值錢的是：當客戶的 Agent 也能直接用同一套組件出界面，你賣的不只是設計，而是「人類＋AI 共用的界面標準」，續費理由更充分。

來源：GitHub meta/astryx

5.claude-quickstarts：Anthropic 官方的 Claude API 起手示例集

Anthropic 官方的 Claude API 參考項目集：從客服 Agent 到自主編程 Agent，覆蓋 Computer Use、Browser Use 與 Managed Agents 等模式。近期的示例包括：按 token 逐步串流、Vault 憑證管理、事件增量（event deltas），以及定時 Agent（讀 Slack 與 GitHub、收到 webhook 後自動修生產錯誤）。對想用 API 接單的人來說，這是最權威的「官方做法」範本，不用再從零摸索調用方式。

3 步上手：
  1. 克隆 anthropics/claude-quickstarts，挑一個與你業務最接近的示例（例如客服 Agent）。
  2. 按 README 跑通一次，確認 API 密鑰、串流與事件處理都正常。
  3. 把示例改成你的場景：換掉提示詞與數據源，先給自己跑一週再談對外交付。

變現角度：官方示例等於「免學費的架構課」：照著它搭出來的 Agent，結構是經 Anthropic 驗證過的，拿去給客戶演示時可信度更高。接 API 集成單子時，直接說「按 Anthropic 官方示例架構搭建」，比「我自己摸索的」更容易讓客戶放心付錢。

來源：GitHub anthropics/claude-quickstarts

6.anthropics/skills：Anthropic 官方的 Agent Skills 標準實現

Anthropic 官方的 Agent Skills 標準實現：Skill 是一個文件夾，內含指令、腳本與資源，Claude 會在需要時動態加載，用來完成特定任務——從按品牌規範生成文檔，到用組織內部流程分析數據。倉庫包含 Anthropic 內部用於生產環境生成 DOCX、PDF、PPTX、XLSX 的 Skill，是學習「怎麼寫一個好 Skill」最直接的參考。11 月 8 日當週熱榜單日新增 793 星、總星數 189,429。

3 步上手：
  1. 克隆 anthropics/skills，讀規範（spec）了解 Skill 的文件結構與加載規則。
  2. 挑一個內部 Skill（例如生成 PPTX 的），跑通一次，看它怎麼組織指令與腳本。
  3. 照葫蘆畫瓢，給自己最常重複的一個任務寫第一個 Skill，放進 .claude/skills/ 試用。

變現角度：Skill 是 2026 年最實在的「賣 know-how」載體：把一個行業的標準流程（例如財報格式、合規檢查清單、品牌文案規範）寫成 Skill，就能打包賣給同行或做成訂閱服務。官方倉庫等於免費教材，先學會寫，再賣給需要的人。

來源：GitHub anthropics/skills

7.把 n8n 工作流換成 Claude Code：先判斷值不值得換

作者親身遷移了一個自託管 n8n webhook（聯繫表單接收端），改由 Claude Code 寫的 Next.js 路由直接走 Resend 發信，全文講清判斷標準：Claude Code 適合「自訂邏輯多、連接器少、有開發者維護」的流程；不適合「非開發者要在畫布上改」的流程。遷移的關鍵步驟是先導出 n8n JSON、讓 Claude Code 寫出規格說明再動手寫代碼，缺一步規格就缺一個功能。價格對照（2026-11-01 核對）：n8n 雲端 Starter 每月 20 歐元起，自託管免費；Zapier Pro 每月 19.99 美元起。

3 步上手：
  1. 從 n8n 導出你要遷移的工作流 JSON，讓 Claude Code 先寫一份規格說明，逐項核對功能有沒有漏。
  2. 讓 Claude Code 寫出替代路由（驗證、限流、發信三件套），本地測試通過再上線。
  3. 保留舊工作流一週並行跑，確認新路由穩定後再停用舊的。

變現角度：「幫客戶把 n8n 流程改寫成代碼」是一類真實需求：客戶嫌 n8n 雲端按次收費貴、又想要更可控的部署，你幫他遷移一次收一筆遷移費，後續還能收維護費。先學會判斷「哪些流程值得遷、哪些不值得」，報價時才不會把自己坑進去。

來源：Smart AI Workspace

8.8 步做出第一個 Claude Skill：不用寫代碼，10 分鐘起步

這份 11 月 5 日發佈、11 月 9 日更新的指南，把做 Skill 拆成 8 步：先選一個重複任務，再建文件夾、寫 SKILL.md（name＋description＋指令）、裝到 Claude 找得到的地方，最後用真實請求測試。核心提醒是 description 最重要——Claude 靠它決定什麼時候加載你的 Skill，寫得太泛就永遠不會被觸發；多數好 Skill 只是純指令，不需要腳本，10 分鐘就能做出第一個。文末附可直接複製的模板。

3 步上手：
  1. 挑一個你本週已經向 Claude 交代過三次的任務（例如寫週報），把步驟寫下來。
  2. 按指南建文件夾與 SKILL.md，description 寫明「什麼情況下用這個 Skill」。
  3. 用三種不同說法向 Claude 提同一個需求，確認 Skill 能穩定觸發。

變現角度：Skill 的變現路徑很直接：把某個行業的標準流程寫成 Skill，打包賣（例如「餐廳月度報表 Skill」「跨境電商選品 Skill」）；或者把 Skill 作為接單的交付物——客戶買的不只是一次服務，而是一套以後能自己複用的工作方法，客單價可以比單次代做高得多。

來源：Skill Directory

9.Claude Code Skills 做 SEO：把每週重複的優化工作變成 Skill

11 月 12 日發佈的實戰指南：Claude Code Skill 就是一個裝著 SKILL.md 的文件夾，Claude 在你的請求符合任務時自動加載。做 SEO 的思路是從「每週都做、已經很熟」的工作開始——寫 meta 描述、檢查頁面——把檢查清單、規則與「好結果長什麼樣」寫進 Skill。個人 Skill 放 ~/.claude/skills/，項目 Skill 放 .claude/skills/；SKILL.md 建議控制在 500 行內，長的參考資料拆到獨立文件。文章同時提醒：插件會以你的用戶權限跑代碼，安裝前要先檢查。

3 步上手：
  1. 挑一個你每週重複的 SEO 任務（例如寫 meta 描述），把你的檢查清單寫下來。
  2. 按指南建 Skill 文件夾，寫好 description（越具體越好），裝到 ~/.claude/skills/。
  3. 先用自己的話提需求，再直接用 /skill-name 調用，兩種方式都測一遍觸發是否穩定。

變現角度：SEO 代運營最大的成本是重複勞動：每個客戶的 meta、標題、內鏈檢查都是同一套流程。把它們寫成 Skill，一個人就能同時服務更多客戶而不掉質量；更進一步，可以把「SEO Skill 包」當作產品賣給同行或中小企業主，按月收訂閱費。

來源：Spearleaf

10.靠 AI Agent 賺錢的 4 種方法：先搞清哪種是比賽、哪種是工資

make.fun 的指南把 AI Agent 變現分成四種，並逐一對照收入方式與門檻：第一，用自己的 AI 編程 Agent 贏 coding 懸賞（bounty），按名次拿 USDC 獎金，免費參賽；第二，讓 Agent 自己參賽、自己領獎（Agent 用自己的 Solana 密鑰對報名、領獎）；第三，把 Agent 做的東西賣給客戶（自動化、小軟件，客戶按件付費）；第四，自己做小產品賣（App、模板、工具，靠用戶付費）。關鍵提醒：懸賞是比賽不是工資，名次之外一分錢沒有，別把它當穩定收入；任何承諾固定收入的課程都是危險信號。

3 步上手：
  1. 讀 make.fun/skill.md，了解參賽要提交什麼（代碼倉庫＋AI 會話記錄）。
  2. 挑一個你有把握做好的公開懸賞，用 Claude Code 或 Cursor 做一次完整參賽流程。
  3. 無論輸贏，把參賽作品整理成作品集——這是接第三種（賣給客戶）生意的敲門磚。

變現角度：四種方法裡最穩的是第三種（賣給客戶），因為客戶付的是「解決問題的錢」，不是「比賽獎金」。建議路徑：先拿懸賞練手、攢作品集，再用作品集去談客戶；等客戶穩定了，再把沉澱的方法做成產品賣第四種的錢。順序對了，每一步都在為下一步鋪路。

來源：make.fun

11.Claude Code 影片自動化：5 步做到 30 天 100 萬播放

作者 Beau Johnson 11 月 7 日分享的實戰系統：用 Claude Code 每晚自動做影片——找熱門話題、寫稿並逐條核對事實（附來源文件與「不要說」清單）、用自己的 ElevenLabs 聲音克隆配音、用代碼做動態圖形，再經 Post Bridge 發到各平台。六個品牌 30 天合計 1,008,021 次播放、200+ 條影片；但作者坦言：一個品牌就佔了一半以上，Facebook 佔約 55% 播放量，而且播放量不等於銷售額。成本細節：X 官方 API 讀一條帖子要半美分，團隊改用 treg 抓取，測試日 137 次調用只花 14 美分，每日上限 1 美元。

3 步上手：
  1. 先定一個你能長期講的主題（產品解說、行業新聞、生活技巧），不要追所有熱點。
  2. 讓 Claude Code 搭一條最小流水線：找話題 → 寫稿 → 核對事實 → 配音 → 出片，先跑通一條 50 秒的解說影片。
  3. 發到 2–3 個平台測一週，看哪個平台的播放與互動最好，再決定主攻方向。

變現角度：「每晚自動出片」本身就是可賣的服務：中小品牌最缺穩定的內容產出，你可以按月收費幫他們跑這套系統；但報價時要學作者的誠實——先講清播放量不等於銷售額，把「內容產出」和「轉化效果」分開報價，客戶反而更信任你。

來源：Shipping Skool

12.230+ 免費 Agent：在 Claude Code 裡跑一間 AI 公司

一份免費的設置指南，核心是一個開源 GitHub 倉庫 The Agency：230+ 個現成的 AI Agent，覆蓋銷售、市場、設計、工程、客服、財務等崗位，複製進 Claude Code 就能用，每個 Agent 只做一件事（找客戶、寫提案、建產品），再由一個 orchestrator Agent 檢查工作質量。作者自述已用 Claude Code 裡的 Agent 自動化了自己創業公司約 90% 的工作。倉庫在 GitHub 上超過 166,000 星，MIT 許可、免費。提醒：Agent 只是提示詞，輸出質量取決於你的指令；Claude Code 本身需要付費計劃（Pro 每月約 18 英鎊起），每個 Agent 都共用同一個用量額度。

3 步上手：
  1. 按指南克隆 agency-agents 倉庫，用安裝腳本列出團隊清單，先只裝銷售與市場兩個部門。
  2. 對自己的業務跑一次「找客戶」提示詞，看 Agent 交回來的名單質量如何。
  3. 只保留效果好的 Agent 團隊，刪掉用不上的——Agent 越多，用量額度燒得越快。

變現角度：這套東西最適合打包成「一人公司啟動包」賣給創業者：幫客戶裝好 Agent 團隊、調好提示詞、跑通第一個獲客流程，一次收費；後續按月收「Agent 維護＋提示詞優化」費。記得先講清成本結構（Claude 訂閱＋用量額度），別讓客戶以為 230 個 Agent 真的零成本。

來源：Fadé Adeniyi 免費設置指南（PDF）

13.賣給內容創作者的 SaaS 工具：用 Claude Code＋Cursor 從零做到 $4.2K MRR

一份完整的實戰劇本：賣給內容創作者的 SaaS 工具，用 Claude Code＋Cursor 搭建，技術棧包括 Claude API、Lovable、Supabase 與 Stripe，Agent（Grok Bot）負責日常交付、客服與彙報，人類只在檢查點介入。成本明細（11 月 15 日核對）：每月工具成本約 30–92 美元；目標是 10 個客戶 × 29 美元／月＝290 美元／月起步；文中引述的同類真實生意自述為 4,260 美元 MRR（未經核驗，僅供參考）。上線時間約 6 個月，每週維護 2–4 小時，難度評級為中級。

3 步上手：
