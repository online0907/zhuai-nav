教程速递｜2026-11-05：15 篇 AI 干货教程

2026-11-05 · 猪猪侠玩AI · 每篇附 3 步上手与变现角度

1.Superpowers：31 万星的开发流程 Skill，让 Agent 按流程干活而不是瞎写

Superpowers 不是一个技巧，而是一套开发流程：里面的 Skill 会自己触发，带着 Agent 走完需求、设计、实现、测试的完整工作流。11 月 2 日当周它有约 31 万星、单周新增约 5900 星，已进入 Anthropic 官方插件市场，支持 Claude Code、Codex、Cursor、Gemini CLI、OpenCode 等十几种工具。

来源：Medium（15 个团队型仓库盘点）

3 步上手：
  1. 在 Claude Code 里用 /plugin install superpowers@claude-plugins-official 安装。
  2. 先拿一个真实小需求走完整流程，别只跑演示项目。
  3. 流程里卡住的环节记下来，写成你自己的补充 Skill。

变现角度：把“流程 Skill + 实测清单”打包成面向开发团队的落地咨询，先帮团队把 Agent 从玩具变成生产线。

2.mattpocock/skills：TypeScript 大牛的日常 Skill 合集，照抄就能用

TypeScript 讲师 Matt Pocock 公开了自己每天都在用的 Skill 合集，约 30.8 万星，9 月初一度冲上 GitHub 日榜第二。里面没有任何应用代码，全是 Markdown 写成的做事方法：怎么写、怎么改、怎么检查。

来源：GitHub mattpocock/skills

3 步上手：
  1. 先读仓库 README，按你的工种只挑 2–3 个 Skill。
  2. 装进 Claude Code 后，用一个真实任务验证它是不是真省时间。
  3. 好用的留进常用库，不好用的直接删，别囤。

变现角度：把“从大牛 Skill 里筛出来的中文实操版”做成内容或小课，卖点是帮读者省掉自己筛选的时间。

3.Karpathy 的 CLAUDE.md：四条规则一张纸，治好 Agent 瞎改代码的毛病

Andrej Karpathy 总结的大模型写代码翻车经验，被整理成一张 CLAUDE.md：只有四条规则，约 22.8 万星。核心是让 Agent 在动手前先想清楚、别凭空编接口、改完自己先验证。仓库虽小，却是本轮热榜里星数最高的几个之一。

来源：GitHub multica-ai/andrej-karpathy-skills

3 步上手：
  1. 把这份 CLAUDE.md 放进你的项目根目录。
  2. 让 Agent 改一处真实代码，观察它是否先读上下文再动手。
  3. 按你的项目特点加一条自己的规则，例如“改动前先跑测试”。

变现角度：把“项目级 CLAUDE.md 定制”做成轻咨询：帮团队把踩坑经验写成一份 Agent 守则，按项目收费。

4.ECC：Agent、Skill、记忆、安检打包在一起的“全家桶”

ECC（原名 everything-claude-code）约 29.5 万星，是这批仓库里 fork 最多的：Agent、Skill、钩子、规则、记忆和安全扫描全打包，作者在 Anthropic 黑客松拿过奖，目标是 Claude Code、Codex、OpenCode、Cursor 通吃。

来源：GitHub affaan-m/ECC

3 步上手：
  1. 先别全装：按 README 只启用记忆和安全扫描两个模块。
  2. 跑一周日常任务，确认它没有拖慢你的工作流。
  3. 再按需加 Agent 和工作流模块，一次只加一个。

变现角度：全家桶最适合做“团队 Agent 落地包”：帮中小团队一次性搭好环境、权限和记忆，按实施项目收费。

5.claude-mem：给 Claude Code 装上跨会话记忆，换个会话也不失忆

claude-mem 约 10.9 万星，单周新增约 5850 星。它在 Claude Code 会话的 6 个关键点挂钩子，把 Agent 做过的事压缩成摘要，存进本地 SQLite，支持全文和向量检索，下次开新会话能自动把相关历史注回上下文，支持 Claude Code、Codex、Gemini 等 7 种以上工具。

来源：GitHub thedotmack/claude-mem

3 步上手：
  1. 按 README 安装插件，确认摘要存在本地，不上传云端。
  2. 做完一个任务后开新会话，问它上次的结论，看记忆是否召回。
  3. 定期清理过期摘要，避免旧决策污染新任务。

变现角度：记忆是长期项目的刚需，把“跨会话记忆配置 + 项目知识库搭建”做成服务，面向接长期单的开发者。

6.做视频动画的 8 个 Claude Code Skill，逐个核对过才敢推

11 月 1 日 X 上的一份中文清单列了 8 个做视频和动画的 GitHub 项目，经逐个核对 README 和许可证，7 个是真 Skill、1 个是可抄的示例项目：pixelfx（244 种像素特效）、huashu-motion（产品发布片）、motion-prompt（192 个动效词典）、animate（单画布讲解动画）、vibe-knowledge-film（抖音风知识短片）、story-studio（历史人物配音视频）、video-editor-skills（达芬奇粗剪），以及 mg-styles-15（15 支动效短片源码）。

来源：AgentGid（逐个核对 GitHub API 与 README）

3 步上手：
  1. 按你要做的视频类型只选一个：产品片选 huashu-motion，讲解选 animate。
  2. 先跑通它自带的示例，再换成你自己的文案和素材。
  3. 出片后人工检查一遍转场和字幕，别直接批量发。

变现角度：视频 Skill 最适合接“批量做短视频”的活：先用 Skill 搭流水线，再按条收制作费，边际成本越做越低。

7.用 AI 代码助手一周赚 300 美元：不会写代码的人也能接单

一位没有任何计算机学位的作者，用 ChatGPT + GitHub Copilot + Replit 做了一个健身教练用的品牌计算器，定价 50 美元，在 Facebook 健身创业群里发截图当天就成交；一周内又卖出 2 个计算器、1 个教练落地页、1 份表格自动化，总共赚了 300 美元，花了约 12 小时。

来源：Vocal（作者自述）

3 步上手：
  1. 选一个具体人群的小工具，例如“教练用的报价计算器”。
  2. 用 ChatGPT 写代码、Replit 免费部署，先做出能用的版本。
  3. 去目标人群的社群发截图接单，先收 50 美元验证需求。

变现角度：别先做产品再找客户，先找一个愿意付 50 美元的人，再为他做东西；一个小工具卖 10 次就是 500 美元。

8.50 位 Reddit 用户 AI 赚钱实测：只有 12% 的人 3 个月后还在赚钱

一份对 r/SideHustle、r/Entrepreneur 等版块 50 多篇帖子的分析显示：42% 的人 30 天内放弃，28% 的人 3 个月后月入不到 100 美元，只有 12% 的人 3 个月后月入 500 美元以上。赚得最多的一批几乎全是卖服务的（AI 辅助写作、设计、剪辑、咨询），而不是卖产品的；最早看到收入也要 60–90 天。

来源：MoneyForge（整理 50+ 篇 Reddit 实测帖）

3 步上手：
  1. 先选“卖服务”而不是“卖产品”：帮人写、帮人剪、帮人做图。
  2. 给自己定 90 天的底线：前 60 天不赚钱是常态，别中途换赛道。
  3. 每天固定 1 小时做获客，比每天换一个新点子重要。

变现角度：把“诚实预期 + 90 天执行表”做成低价资料包，卖点是帮人避开“第一个月就月入过万”的幻想，照着做就能回本。

9.62 个有真实收入的 AI 副业清单：只看支付验证过的数字

The AI Receipts 整理了 62 个有真实收入的 AI 业务，全部经过支付验证而非口头自述：Postiz 月入 35.2 万美元、AEO Engine 18 万美元、PropGPT 10.5 万美元；其中 29 家给了完整拆解，7 家由一人创办。清单按 AI SaaS、服务中介、AI 应用等分类，附带每个业务的获客渠道和验证状态。

来源：The AI Receipts（TrustMRR 支付验证，2026-11-04 更新）

3 步上手：
  1. 按“一人能做”筛选，先看 7 家一人创办的业务怎么获客。
  2. 挑一个和你现有技能最接近的，抄它的定价和渠道。
  3. 先做最小版本验证有人付费，再谈放大。

变现角度：这份清单本身就是选品工具：每周跟一次榜单变化，挑刚起量的一家写拆解，内容号的选题就有了。

12.X 只读挖到：1 个 Agent 控制所有 Agent 和应用，Grok Bot + 开源桌面端是最佳搭配

@aiwarts 11 月 4 日分享：用 1 个 Agent 控制所有 Agent 和应用的新技巧，介绍了两个新开源项目；最佳搭配是 Grok Bot 加 Vercel 开源的 agent-desktop，可以操控本机的其他 Agent、操作剪映做 AI 剪辑，第二次操作可不消耗额度。

来源：X @aiwarts（只读浏览）

3 步上手：
  1. 先装好 agent-desktop，确认它能看到本机的其他 Agent。
  2. 从一个低风险任务开始，例如让它操作剪映做一条简单剪辑。
  3. 跑通后再把重复任务交给它，关键操作保留人工确认。

变现角度：把“多 Agent 编排 + 剪辑自动化”做成给内容团队的效率服务，按月收维护费；能省人力的方案最好卖。

13.X 只读挖到：Adrian Punk 的 Skill 全套值得抄，Q 版个人 IP 一套做法就能做

@Sunkeke_AI 11 月 5 日大力推荐 Adrian Punk 的所有 Skill；引用的 11 月 4 日文章介绍 Punk IP skill，教人用同一套做法打造自己的 Q 版个人 IP 形象。个人 IP 的视觉一致性，以前要靠设计师，现在一套 Skill 就能批量出图。

来源：X @Sunkeke_AI（只读浏览）

3 步上手：
  1. 先定好你的 Q 版形象三要素：发型、配色、标志性物件。
  2. 按 Skill 的做法批量生成同一形象的不同场景图。
  3. 挑 3 张最像的定为标准形象，以后所有内容都用它。

变现角度：Q 版 IP 形象设计是创作者的刚需：帮人定形象、批量出图，按套收费；做得好的客户还会回来做表情包和周边。

14.X 只读挖到：30 秒手绘风复古动画 MV 怎么做？人物一致性和配音是两道坎

@HaileyAILabs 11 月 5 日分享 30 秒手绘风复古剧情动画 MV《谁偷走了我的影子？》，用 Muse 反覆打磨时遇到人物一致性及配音问题，最后改用 Opus 5.5 处理配音才完成。复盘的价值在于：问题不在生成，而在“同一角色演完整支 MV”。

来源：X @HaileyAILabs（只读浏览）

3 步上手：
  1. 先定角色设定图，每一镜都贴同一张参考图锁住形象。
  2. 分镜先出静帧，确认人物一致后再做动态和配音。
  3. 配音单独处理，音画对不上就重配，别将就。

变现角度：动画 MV 是品牌和音乐人的高价需求：先做一支免费样品，再按 30 秒一支报价，人物一致性就是你的卖点。

变现角度：把“AI 工作流 + 面试话术”做成求职辅导产品：帮人把 AI 能力翻译成面试官听得懂的成绩，需求正在起来。
