1.Claude Code 新手教程：安裝、CLAUDE.md、第一個項目

從零開始用 Claude Code 的完整上手指南，2026 年 11 月 21 日更新：講安裝、項目文件規範和「先規劃再寫代碼」的正確姿勢。變現角度：學會這套流程就能接「AI 幫我做個小工具／小網站」的 freelance 單，是後續所有 vibe coding 接單的基礎功。

來源：CodeUtility

3 步上手：
  1. 用官方命令安裝（Mac／Linux：curl -fsSL https://claude.ai/install.sh | bash；Windows 用 PowerShell 腳本），新建文件夾並 git init 後運行 claude 登錄。
  2. 寫一份 10–30 行的 CLAUDE.md，只寫 AI 讀代碼發現不了的規則，或用 /init 讓它自動生成初稿。
  3. 先按 Shift+Tab 進 plan mode 讓它出 5–8 步小計劃，讀完確認後再一步步執行，每步用測試或構建命令驗收。

2.用 Claude Code 做你的第一個 App：記賬本實戰

手把手帶零基礎用戶用 Claude Code 做出一個能存數據的記賬網頁，核心方法是「先搭骨架、一次只加一個功能、每次親眼檢查」。變現角度：做出來的記賬頁可改造成「小商家記賬／報價小工具」按單交付，是低成本練手加接單的樣板。

來源：AI Trend Catchup

3 步上手：
  1. 建空文件夾 gaegebu，在裡面啟動 claude，先進 plan mode 拿到最小版計劃。
  2. 先只做骨架（日期、事項、金額輸入框＋Add 按鈕＋下方表格），在瀏覽器打開親手錄一筆驗證。
  3. 再逐個加功能（合計、刪除、刷新後數據保留），每加一個就測試一次，順手檢查文件夾裡沒有誤放密碼或 API 密鑰。

3.我如何用 Claude 把副業自動化，睡覺時也在賺錢

作者用 Python＋Anthropic API 把一份小眾技術簡報和代碼審計服務改造成 cron 定時自動跑的流水線，2026 年 11 月 2 日發布。變現角度：把「人工整理的簡報／審計報告」變成可訂閱的自動化服務收訂閱費或按單收費，省下的週末時間就是直接利潤。

來源：DEV

3 步上手：
  1. 裝最新 Anthropic SDK（pip install anthropic），寫腳本拉取 GitHub 熱門倉庫和技術討論作為原材料。
  2. 用 claude-opus-5 做分析並輸出結構化 JSON（用 output_config 強制格式，替代已廢棄的 temperature 等舊參數），結果存入數據庫。
  3. 用 cron 定時觸發，自動發簡報並觸發 Stripe 賬單，付費審計走同一條流水線。

4.開發者 API 被動收入指南：把 AI 能力包成微 API 來賣

教開發者把一個 AI 處理能力（如把報錯日誌翻成大白話）包成輕量 API 產品，2026 年 11 月 9 日發布。變現角度：面向其他開發者按調用量收費的微 SaaS；一個小眾但高頻的痛點 API 就能形成持續收入，適合技術型副業。

來源：DEV

5.n8n AI 教程：3 個實測工作流，從郵件摘要到問答 Agent

基於 n8n 2.47.3 實測的三個工作流，帶真實測試結果和踩坑記錄，2026 年 11 月 11 日核對節點清單。變現角度：這三類工作流正是中小企業願意付費的自動化服務（郵件處理、發票分揀、內部問答），學會後可按項目收費交付。

來源：MIA Automation

3 步上手：
  1. 搭第一個工作流：IMAP 觸發器讀新郵件 → Basic LLM Chain 按固定兩行格式（Gist／Action）摘要 → 發郵件給自己。
  2. 升級做郵件分類：先用規則做分類兜底，再讓模型打分，模型輸出解析失敗時不讓整批 38 封郵件一起失敗。
  3. 做問答 Agent：Agent 節點自己查賬本數據回答「哪張發票最逾期」，答不出的（如未存的電話號碼）要明確承認不知道。

6.用 n8n 搭 AI Agent、開一家高收入自動化代理服務

不用寫代碼，用 n8n 可視化節點搭一個「自動篩選銷售線索並分發到 CRM」的 AI Agent，並把它包裝成服務賣給本地商家。變現角度：文章稱這類自動化部署可按每個項目 500–3000 美元以上收費（作者口徑，未獨立驗證），核心是幫商家省人工、24 小時不漏單。

來源：Make Money Blog

3 步上手：
  1. 在 n8n 新建工作流，放一個 Webhook 或 Google Forms／Typeform 觸發節點，接客戶網站聯繫表單的新提交。
  2. 拖入 Advanced AI 的 AI Agent 節點（選 Tools Agent），接上 LLM 和網絡檢索等工具，讓它判斷線索預算是否真實、是否值得跟進。
  3. 跑通後把合格線索自動路由進 CRM 並郵件通知商家，整理成可演示的案例去談客戶。

7.用 ChatGPT＋n8n 自動生成無臉 Shorts

一條 n8n 流水線：輸入主題和圖片，ChatGPT 寫腳本、ElevenLabs 配音、Creatomate 自動合成帶動畫字幕的豎屏短視頻並上傳 YouTube。變現角度：無臉頻道靠量取勝，自動化把單條製作成本壓到最低；做到 1000 訂閱＋90 天內 1000 萬 Shorts 播放即可申請 YouTube 合作夥伴計劃分成。

來源：Creatomate

3 步上手：
  1. 在 ElevenLabs 建 API key 並接到 Creatomate 項目，再導入現成的 Faceless Short 模板。
  2. 在 n8n 裡搭流程：手動觸發 → 輸入主題和 6 張圖 → ChatGPT 寫旁白、標題和簡介。
  3. Creatomate 節點按模板渲染成片、生成同步字幕，n8n 下載 MP4 後自動上傳到 YouTube。
