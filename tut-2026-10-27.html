1.把 Agent 的“开工收工例行程序”写成 Claude Code Skill，告别每次复制提示词

一位开发者把每天定时跑的 Claude Code 会话的固定流程——开工读哪几个文件、收工写什么样的交接文档——从任务提示词里抽出来，做成一个 Skill。Skill 就是一个带 SKILL.md 的文件夹，描述写在前言里常驻可见，详细步骤只在触发时加载，既省上下文又不怕被跳过。

来源：DEV

3 步上手：
  1. 在项目里建 .claude/skills/<名字>/SKILL.md，写好 name 与 description，前言里写清触发场景（开工／收工）
  2. 把“读哪几个文件、按什么顺序做、交接文档写什么”写进正文，任务提示词只留一句话指向这个 Skill
  3. 跑两次定时会话验证：开工是否自动读对文件、收工交接是否完整，再把 Skill 提交进模板仓库复用

变现角度：把这套“定时 Agent 例行程序”打包成服务，帮小团队把日报、周报、内容复盘做成无人值守流程，按月收维护费。

2.团队用 Claude Code Skill 的分界线：什么放 CLAUDE.md，什么做成 Skill

一篇 10 月 27 日的团队实践：CLAUDE.md 放每天都要用的东西（构建测试命令、项目是什么、什么情况下拒绝），Skill 放某一天才需要的流程（发版清单、数据库迁移、新接口写法）。Skill 还分项目级、个人级、企业级三档，名字冲突时企业级优先于个人级、个人级优先于项目级。

来源：DEV

3 步上手：
  1. 先列一张表：把团队每天必用的规则写进 CLAUDE.md，把偶发流程逐个抽成 Skill
  2. 给 Skill 起带仓库前缀的名字（如 deploy-web），避免个人旧 Skill 抢跑同名流程
  3. 把项目级 Skill 提交进仓库，让新成员 clone 下来就自动获得同一套流程

变现角度：给小公司做“AI 编码规范落地”咨询：一次梳理＋一套 Skill 模板，按项目收费，比卖课更实在。

4.Claude Duet 是什么、怎么排队：Anthropic 的“主动找你”的 Agent

Anthropic 10 月 21 日推出的 Claude Duet 进入研究预览：不再等你提问，而是主动推送晨间简报、在你离开后继续干活、只在真正需要你时才打扰。定位是给专业人士与小企业主减杂活，不同于普通 Claude，Duet 是独立的 iPhone、安卓与网页应用。

来源：DEV

3 步上手：
  1. 先读清 Duet 的定位：晨间简报＋离线续跑＋关键节点请示，判断它能接你哪类杂活
  2. 按文内指引加入候补，拿到资格后先接一个低风险流程（如每日资讯简报）试跑一周
  3. 把试跑中“它主动推对了什么、推错了什么”记下来，再决定是否扩大到客户业务

变现角度：等 Duet 开放后，第一批帮小企业主搭“晨间简报＋待办跟进”服务的人，能吃到一波尝鲜红利。

5.用 Claude Code 跑求职循环：美国后端岗位一半是重复贴，先去重再投递

一篇实战记录：作者用 Claude Code 做求职搜索时发现，美国后端岗位里约一半是重复发布。他的循环是：每天按上次时间戳拉新帖，按 jobId 与公司＋标题去重，排前五重点跟进；每份岗位给决策人或招聘者写一封带具体信息的私信，同时照常走网申；5 个工作日后带一个新事实跟进一次。

来源：DEV

3 步上手：
  1. 把求职搜索的条件与时间戳固定下来，每天只拉新增，避免反复刷到同一批帖子
  2. 去重后按匹配度、申请人池、发布日期、招聘速度排前五，其余的先放一边
  3. 每份重点岗位写一封针对性私信＋正常网申，5 个工作日后跟进一次，每周清理已过期岗位

变现角度：把这套“去重＋排序＋私信”流程做成求职辅导服务，按拿到面试收费，比泛泛的简历修改更好卖。

6.48 行代码手写 Next.js Agent 循环：不用框架，还顺手堵住了 API 密钥泄露

一篇 10 月 27 日的实战复盘：作者没用 Agent 框架，在 Next.js 里手写了 48 行 Agent 循环，单次回答的提示缓存成本不到 1 美分。真正的坑在部署：构建工具会把 .env、.env.local 里的全部变量写进 next-env.mjs，Claude API 密钥差点随构建产物泄露——修复只需 4 行 shell。

来源：Medium

3 步上手：
  1. 先照着写出最小循环：工具调用＋提示缓存＋一轮对话，跑通后再加功能
  2. 部署前检查构建产物里有没有 .env.local 的值，确认密钥不在输出文件里
  3. 把“部署前密钥检查”写成 4 行脚本，放进每次发版的固定步骤

变现角度：把“轻量 Agent＋部署安全检查”做成给独立开发者的付费模板或审计服务，一次检查收一次费。
