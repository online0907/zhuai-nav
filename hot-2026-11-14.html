AI 速遞｜2026-11-14

2026-11-14 · 猪猪侠玩AI · 每天更新 5 条

1.OpenAI 解散獨立機器人團隊：通用模型直接控機械人

Fortune 11 月 13 日獨家報道，OpenAI 已解散獨立機器人團隊，研究人員併入首席研究官 Mark Chen 領導的主研究團隊，應用機器人與硬件團隊併入 Greg Brockman 領導的 Applied 組織。OpenAI 向 Fortune 確認了這次重組，理由是 GPT-6 Astra 等通用模型已可直接驅動機械人——英偉達一項研究顯示，Astra 驅動的 Agent 在模擬操作基準上成功率 74.8%，高於最佳專用機械人模型的 51.0%。公司稱機器人仍是長期願景，人形機械人公開演示目標仍為 2027 年。這是 OpenAI 第二次解散機器人團隊，上一次是 2020 至 2021 年。

來源：Fortune

對你有什麼用：「模型即機械人大腦」正在成真，專用機械人模型的護城河在變薄。做 AI 創業或接單的，別再押注「為某款機械人寫專用模型」，轉向通用模型＋硬件集成的活，需求會先起來。

2.Cursor 供應鏈中毒完整調查：洩露的供應商密鑰，讓毒版 Claude Code 擴充觸及約 5,000 用戶

11 月 13 日 Cursor 公佈完整調查結果：攻擊者利用其 AI 供應商 Fireworks 洩露的一把 Cursor 授權密鑰，複製了共享儲存桶中的編碼 Agent 軌跡（少於 0.05% 用戶的軌跡受影響，少於 0.01% 客戶的 API 憑證外洩）；10 月 29 日，攻擊者用竊取的憑證把帶 SSH 後門的 Claude Code 2.1.312／2.1.313 惡意版本放到 Cursor 擴充市集的緩存上，約 11 小時內最多 5,000 名用戶可能收到。Cursor 強調 Anthropic 並未發佈該版本、這不是 Anthropic 產品的漏洞。公司已將推理全部遷離 Fireworks，最後一次攻擊活動於 11 月 1 日被攔截，事件已受控。

來源：Cyber Security News

對你有什麼用：如果你在 10 月 29 日前後經 Cursor 裝過 Claude Code 2.1.312／2.1.313，只卸載擴充不夠——還要清掉 SSH 密鑰與啟動腳本、輪換憑證。教訓更通用：供應商密鑰洩露一樣能毒掉你的工具鏈，給客戶做 Agent 交付時，密鑰分級和輪換要寫進報價裡。

3.OpenAI 上線 ChatGPT Wallet，AI 助手能替你下單付款了

OpenAI 11 月 13 日推出 ChatGPT Wallet，配合常駐助手 dots 使用，讓 AI 助手能代用戶完成購物付款。錢包與 American Express、Mastercard、Visa 合作，首發僅限美國 18 歲以上 ChatGPT Pro 訂閱用戶，逐步開放。每筆購買都要用戶先核對商品、總額和卡片，再用人臉或指紋等安全驗證確認；支付時用一次性令牌代替真實卡號，助手和商家都看不到真實卡信息（OpenAI 官方說法）。OpenAI 稱上線初期交易零抽成，未來可能支持在預設額度內全權委託購買。

來源：9to5Mac

對你有什麼用：「AI 幫你買東西」從演示變成了真能付錢的產品，Agent 電商的口子打開了。做電商、帶貨或獨立站的人，現在就該想想自己的店怎麼接待 AI 買家，別等它普及了才追。

4.DeepSeek 把 App 全部能力開放成 API：搜索、讀檔、語音一次到位

11 月 13 日 DeepSeek 把消費端 App 背後的能力全面開放給開發者：網頁搜索、圖片搜索、深度思考搜索、文件解析、URL 讀取、安全檢查、語音功能，全部可通過 API 調用。核心模型是新推出的 deepseek-flash（即 V4.1-Flash-1017），橫跨 Messages、Responses 和 Chat Completions 三個端點；Search、Fetch、OCR、語音識別（ASR）與語音合成（TTS）也可作為獨立 API 單獨調用。工具費另計（據 DeepSeek 文檔，搜索每千次 0.75 美元），面向公眾的應用須開啟安全檢查；DeepSeek 同時開源了一個前端演示客戶端。

來源：Crypto Briefing

對你有什麼用：以前要自己拼搜索＋解析＋語音三套服務才能做的產品，現在一個 DeepSeek API 就能跑通，開發成本直接砍半。做 RAG、信息差產品、文檔處理工具的，先用 deepseek-flash 跑個 MVP，記得把工具費算進定價。

5.Edge0 開源 145B 參數模型，號稱能在筆記本上跑

小團隊 Edge0 於 11 月 12 日開源 Edge0-145B（另有 120B 小版本），號稱首個能在個人電腦上運行的 1450 億參數開源模型，在 48GB 內存筆記本上速度超過每秒 80 token。模型為混合專家架構，總參數 145B、每步實際激活約 100 億，權重在 Hugging Face 上架，推理框架與部署工具在 GitHub 以 Apache 2.0 開源（權重用 Edge0 自有社區許可）。但全部跑分均為 Edge0 自家測試（公司自述口徑，DeepSWE 1.1 得分 64.6 等），技術報告尚未發佈，尚未有獨立第三方驗證；GitHub 倉庫一天內獲星超 1 萬。

來源：AI Frontier Post

對你有什麼用：如果屬實，本地跑大模型做 Agent、寫代碼就不用再按 token 交雲端賬單，數據也不出本機；但先別急著換工作流——等獨立實測出來再決定，跑分目前只是廠商自述。
