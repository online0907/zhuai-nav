1.Claude Code 新手入門：從零到 productive 的完整指南

2026 年 11 月 9 日重寫的新手教程，講清 Claude Code 的安裝、Plan Mode、CLAUDE.md 與模型選擇，預設模型為 Opus 5.5。

3 步上手：
  1. 訂閱 Claude Pro（$20／月起，含 Claude Code）或準備 API 賬號，用官方原生安裝器安裝；
  2. 在一個能隨時還原的小項目裏開第一個會話，先讓它解釋項目、再做一個可檢查的小改動；
  3. 非小事一律先按 Shift+Tab 進 Plan Mode，讓它先出計劃、你批准後再動手改文件，並跑一次 /init 生成 CLAUDE.md。

變現角度：把「AI 結對編程」變成接單能力——用 Claude Code 接小型網站／腳本外包，Plan Mode＋CLAUDE.md 能顯著減少返工，等於用同一份時間接更多單；也可把這套流程做成付費教程／諮詢。

來源：nxcode.io

2.本週 GitHub 最熱 AI 項目：給編程助手加記憶、用 Zig 寫的無頭瀏覽器

以 2026 年 11 月 2 日 GitHub 日榜為底的趨勢盤點，claude-mem 單日漲星 1500+、T3 Code 單日漲星 3000+，另有離線聽寫工具 Handy 等。

3 步上手：
  1. 先讀文章的 Quick picks，按需求選一個：要跨會話記憶選 claude-mem，要手機遙控多個編程助手選 T3 Code，要離線聽寫選 Handy；
  2. 去對應倉庫讀 README 的安裝與許可說明（注意 claude-mem 有付費託管功能、OpenBot 需許可證）；
  3. 在一個真實小項目上試用一天，記錄「省了多少次重複交代上下文」，再決定是否納入日常工作流。

變現角度：省成本路線——claude-mem 減少重複提示詞消耗的 token，Handy 替代付費聽寫訂閱；選題路線——照着榜單做「本週最熱 AI 開源項目」解讀內容，是穩定的流量選題。

來源：Toolclove

3.93 個 AI 工程實戰項目合集：從 OCR 到多智能體的工作手冊

4.15 分鐘跑起第一個本地大模型：Ollama＋Qwen 3.5 9B

2026 年 11 月 4 日更新的保姆級教程，8GB 顯存就能跑帶視覺、26.2 萬上下文的 Qwen 3.5 9B，全程離線、零訂閱費。

3 步上手：
  1. 去 ollama.com 下載安裝 Ollama（Linux 可用官方安裝腳本）；
  2. 終端執行 ollama pull qwen3.5:9b（約 6GB），再執行 ollama run qwen3.5:9b 開始對話；
  3. 需要寫代碼時再拉 qwen2.5-coder:7b，需要圖形界面時裝 LM Studio，二者可並存。

變現角度：省成本——本地模型無 token 賬單，適合把高頻、私隱敏感的寫作／整理／客服草稿全部轉到本地；也可幫注重私隱的小團隊部署本地 AI 工作台收服務費。

來源：InsiderLLM

5.不買 Claude 訂閱也能用 Claude Code：Ollama 本地模型接管法

用 Ollama 的 Anthropic 兼容 API 把 Claude Code 的「大腦」換成本地開源模型（如 Qwen），一條命令完成設置，但明確說明它不是真正的 Claude。

3 步上手：
  1. 裝 Ollama 0.15+ 與 Claude Code，確認本地機器顯存夠用（文中提到 glm-4.7-flash 在 6.4 萬上下文時約需 23GB 顯存，小機器應選更小的模型）；
  2. 用 ollama launch claude 一鍵設置（它會寫入 ANTHROPIC_AUTH_TOKEN 與 ANTHROPIC_BASE_URL=http://localhost:11434）；
  3. 把上下文長度設到 64000（OLLAMA_CONTEXT_LENGTH=64000 ollama serve），先在小倉庫實測代碼補全與改寫質量，再決定是否用於正式項目。

變現角度：省成本——本地模型無用量上限，適合把 Claude Code 的工作流用於練手、教學和小項目；注意：開源模型效果不等於 Claude，別拿它向客戶承諾同等質量。

來源：AI Stack Signal

7.n8n＋AI 影片 API：把 40 張產品圖批量變成短片的工作流

2026 年 11 月 4 日文章，講 n8n 如何當「指揮家」調度影片生成 API：表格新增一行就自動生成影片、存盤並通知，含 4 個可複製的工作流示例。

3 步上手：
  1. 在 n8n 裏搭核心循環：觸發器（表格新行／定時）→ 大模型改寫提示詞 → HTTP Request 節點調用影片 API → Wait 節點輪詢狀態 → 下載存盤並通知；
  2. 關鍵點：影片生成是異步的，必須加「等待 20–30 秒後輪詢」循環，不能讀第一次返回就當完成；
  3. 先用免費路線練手（自託管 n8n 社區版不限執行次數＋免費影片模型做測試），跑通後再接付費模型。

變現角度：賣給電商／短片商家——「產品圖批量變影片」是真實存在的按條收費需求；也可把工作流模板本身打包出售，或接 n8n 自動化定製單。

8.n8n 新手第一課：15 分鐘搭出第一個自動化

2026 年 11 月 6 日更新的新手指南，講清雲端試用與免費自託管二選一，以及觸發器＋節點＋測試＋發布的標準動作，官方稱第一個工作流約 15 分鐘。

3 步上手：
  1. 選雲端（14 天免費試用，不用管服務器）或自託管社區版（免費、功能基本齊全）；
  2. 照官方新手模板做一個每日 8 點跑的報告流：定時觸發 → HTTP Request 拉數據 → Edit Fields 整形 → 存表／發郵件；
  3. 每加一個節點就點 Execute step 單步驗證，全跑通再點 Publish，別在編輯器裏「看着像通了」就發布。

變現角度：n8n 是目前接自動化外包最順手的工具之一——表單自動分流、郵件自動分類、客戶諮詢自動起草回覆，都是中小企業願意按月付費的活；先拿自己的重複工作練手，再拿案例去接單。

來源：Lilach Bullock

9.無臉 YouTube 影片製作全流程：選題、腳本、配音、過審檢查一次講清

以一個 90 秒科普短片為貫穿案例的六步指南，YouTube 規則核對到 2026 年 11 月 7 日，重點講了 AI 標籤、原創性與素材版權三道檢查。

3 步上手：
  1. 選一個畫面能講明白的、可重複的格式（如動畫解說、錄屏教程），先寫腳本和分鏡再碰素材；
  2. 配音可用自己的聲音、AI 音色或克隆自己的聲音，剪輯時以旁白為準逐句配畫面、加字幕；
  3. 上傳前做三項檢查：是否需要 AI 標籤、是否屬於 YouTube 點名的「圖片輪播／模板化劇情／滾動文字」等不予變現的類型、每個素材是否有權使用——先私密上傳自查再公開。

變現角度：廣告分成（需加入 YouTube 合作伙伴計劃並通過原創性審核）＋選題本身可複用：歷史、科普、財經解說等高 RPM 賽道，一條跑通的格式可批量生產；但注意低質模板化內容會被拒變現，別走量產捷徑。

來源：ChatCut

10.用 Claude＋Higgsfield 做無臉頻道：從調研、寫稿到成片的三步工作流

11.賣 AI 提示詞賺錢：從選品類到定價、上架的完整新手指南

講清提示詞包這個品類怎麼做：PromptBase、Gumroad、Etsy、Payhip 四個渠道的定位與費用，10–30 條的小包賣 $7–$19、50–100 條的主題包賣 $19–$47。

3 步上手：
  1. 選一個窄人群＋明確結果（如「房地產經紀人的房源描述提示詞」），在 ChatGPT／Claude 裏逐條實測，留效果好的、刪掉通用廢話；
  2. 打包成 PDF 或文本文件，定價先取 $9–$15 的低位，用前幾單換評價；
  3. 同一包多平台上架（PromptBase 吃站內流量、Gumroad 適合自己引流、Etsy 觸達非技術買家），不簽獨家。

變現角度：零庫存數字產品，邊際成本接近零；文中算術口徑：$12／包 × 100 單／月＝$1,200／月（作者測算示例，非保證收入）。注意：別爬別人的提示詞庫倒賣，會侵權封店。

13.三個月連發 3 個 AI MVP：從會議紀要工具裏學到的發貨經驗

3 步上手：
  1. 選一個你自己正在忍受的痛點（如會議紀要整理），MVP 只做一件事：粘貼原文 → 輸出帶待辦事項的結構化紀要；

  3. 把 MVP 發到你已活躍的社群（如 Discord）找第一批真實用戶，作者第一個項目兩週拿到 12 個用戶，全部來自社群。

變現角度：「小而真的工具」最容易變現：會議紀要轉任務管理（對接 Jira／Linear／Asana）這類 B 端小工具可按月訂閱收費；作者的教訓是別先做大而全的 AI 包裝器，先讓一個小功能收到錢。
