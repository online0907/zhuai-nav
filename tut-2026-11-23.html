1.OpenSRE：讓 AI 自動修好掛掉的 CI

開源命令列 agent，讀失敗的 CI 日誌、定位原因並提交修復給你審核。2026-11-23 當日登上 GitHub 熱榜第 13 名，當天新增 399 stars，總計 14,534 stars（Python，Apache-2.0）。

來源：GitHub · Tracer-Cloud/opensre

3 步上手：
  1. 第 1 步：克隆倉庫按 README 自托管部署。
  2. 第 2 步：接入自己的模型和 CI（如 GitHub Actions），只連接可信的 MCP 伺服器。
  3. 第 3 步：先用審批模式跑：它讀失敗日誌、追蹤根因、推送修復 PR，人工確認後再合併。

變現角度：給中小團隊做 CI 排障／DevOps 提效服務，按次或按月收費；自己用則省下半夜爬起來修構建的時間。注意：仍是公開 alpha 版，預設 /auto 可能不經確認就寫檔案，先關掉再上生產。

10.給 Claude Code 寫帶腳本的 skill：重複工作一次固化、次次省 token

2026-11-21 發佈：作者用 Claude 跑自己的全部生意，核心方法是把重複任務寫成 skill；關鍵升級是把「不用判斷的步驟」移進 scripts/ 腳本——腳本代碼不進上下文，只讀輸出，token 成本大降。實測發版流程：手工跑 12 輪對話、約 283,000 輸入 tokens；改成 skill 加腳本後 2 輪、62,000 tokens（作者實測口徑）。

來源：hassandev.me

3 步上手：
  1. 第 1 步：先跟 Claude 走通一次重複任務（不要一上來就寫 skill）。
  2. 第 2 步：在同一個會話裡讓它把流程寫成 .claude/skills/&lt;名字&gt;/SKILL.md。
  3. 第 3 步：把不用判斷的步驟移進 scripts/ 腳本，只留判斷給模型，並用 --dry-run 先演練。

變現角度：把高頻重複工作固化成 skill，省 token 就是省錢；可打包成「AI 業務自動化」服務賣給小團隊——判斷規則：能寫成 if 語句的步驟進代碼，需要讀雜亂內容再判斷的留在指令裡。

11.搭 AI agent 別先上框架：一個 cron 加一個腳本就夠了

2026-11-18 發佈：作者的生產經驗——真正跑起來的 agent 大多不是框架搭的，而是一個定時任務加確定性腳本，只把「需要判斷的那一步」交給 Claude；文章對照 Anthropic 官方文件講清三條路線（Messages API 自寫循環、Agent SDK、Claude Code 非交互運行）。

來源：roughworks.ca

3 步上手：
  1. 第 1 步：定一個 cron 加 Python 腳本做骨架（確定性的步驟全放腳本裡）。
  2. 第 2 步：只把需要判斷的一步交給 Claude（三選一：Messages API、Agent SDK、或 claude -p）。
  3. 第 3 步：跑完把結果寫進 git 留檔、可複核。

變現角度：用最小成本給客戶搭「半自動 agent」：不用養重框架、不用長期維護複雜系統，按項目收搭建費加按月收維護費。
