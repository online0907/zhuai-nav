1.Anthropic 官方插件目录：插件生态刚起步时占位

9.Agentic Coding 十月实战：1–2 天交付生产级应用

6 点 Agentic Coding 工作流浓缩：强制 agent 先提问再动手、要求 agent 运行程序自行验证、大任务先写 Markdown 总纲再拆子文件。

视频：https://www.youtube.com/watch?v=N6YKW_nv9I4

上手 3 步：
  1. 写一份 prompt 模板：强制 agent 动手前先向你提问澄清需求
  2. 每个任务要求 agent 自己运行程序验证结果，而不是只给代码
  3. 大任务先让 agent 写 Markdown 总纲，拆分子文件再逐个执行

变现角度：1–2 天交付意味着可以接外包急单、快速验证 SaaS 想法，交付速度本身就是报价筹码。
