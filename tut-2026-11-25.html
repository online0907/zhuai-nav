教程速遞｜2026-11-25

2026-11-25 · 猪猪侠玩AI · 每天更新 13 篇

1.n8n nod：n8n 官方開源個人 Agent，給它一台自己的電腦

n8n 剛開源的個人 Agent：跑在你自己的機器上，用你選的模型，會追發票、準備會議、取消試用訂閱，直接在真實網站上操作，動手前先問你一句。跟雲端 Agent 最大的分別是：電腦是你的，數據不出門。

來源：GitHub · n8n-io/nod

3 步上手：
  1. 按 README 在本地裝好 nod，選一個你常用的模型接上。
  2. 先開最小權限：只准它讀日曆和郵件，試著讓它幫你準備一場會議。
  3. 逐步放開：追發票、取消試用這類花錢的操作，先設好「動手前必問」的規則再放行。

變現角度：幫中小企業部署「不上雲的個人 Agent」，按部署加維護收費；自己用則是把每月重複的行政雜事自動化，省下來的時間就是收入。

2.Firecrawl：給 Agent 的知識基礎設施，一個 API 搞定搜索與抓取

熱榜項目：讓 Agent 更聰明的知識基礎設施——搜索、抓取、調用 550 多個數據源，全部走一個 API。不用再為每個網站寫一套爬蟲，Agent 需要資料時直接問它。

來源：GitHub · firecrawl/firecrawl

3 步上手：
  1. 註冊拿 API key，照文件跑通一次搜索加抓取。
  2. 把它接進你的 Agent 或 n8n 工作流，取代零散的爬蟲腳本。
  3. 設好抓取頻率與緩存，別讓重複請求吃掉額度。

變現角度：接「競品監控、價格追蹤、行業情報」這類定製數據服務：客戶按月付費，你的成本只是一個 API；也可以把它包進自己賣的 Agent 產品裡。

3.Plannotator：給 Agent 的工作台，審查完一鍵把反饋發回去

本週熱榜第一：專門管 Agent 的工作台——塑形、決策、規劃、批註、審查代碼、跟團隊分享，改完一鍵把反饋發給 Agent。適合已經讓 Agent 寫代碼、但審查流程一團亂的團隊。

來源：GitHub · backnotprop/plannotator

3 步上手：
  1. 克隆倉庫跑起來，把正在進行的 Agent 任務接進去。
  2. 先用它審查一次 Agent 的輸出：標出要改的地方、寫清原因。
  3. 把「審查—反饋—重跑」跑成固定流程，團隊每人照同一套來。

變現角度：接 AI 開發團隊的流程諮詢：很多小團隊 Agent 用得很多、管得很亂，幫他們搭一套審查流程就是一單生意；自己團隊用則直接省下返工時間。

4.Chrome DevTools MCP：讓 coding agent 直接用上 Chrome DevTools

Google Chrome 團隊的官方 MCP 伺服器：把 Chrome DevTools 交給 coding agent 用，Agent 可以直接調試網頁、看報錯、測性能，不用你來回複製控制台信息。

來源：GitHub · ChromeDevTools/chrome-devtools-mcp

3 步上手：
  1. 照 README 把 MCP 伺服器接進 Claude Code 或 Cursor。
  2. 開一個有前端報錯的項目，讓 Agent 自己開瀏覽器重現問題。
  3. 把「先在瀏覽器裡驗證再改代碼」寫進你的 CLAUDE.md，讓它變成默認流程。

變現角度：前端調試是最耗時的接單環節之一：用這套工具把排錯時間砍半，同樣的單接得更多；也可以做成「前端問題定位」的小服務，按次收費。

5.AG-UI：Agent 與前端對話的協議，讓 Agent 走進你的應用界面

Agent-User Interaction Protocol：讓 Agent 不只在聊天框裡回文字，而是直接走進前端應用——在界面裡操作、更新狀態、跟用戶即時互動。做 AI 產品的人值得跟進的底層協議。

來源：GitHub · ag-ui-protocol/ag-ui

3 步上手：
  1. 讀一遍協議文檔，理解 Agent 事件怎麼跟前端狀態同步。
  2. 找一個現成的前端項目，照示例接一個最小的 Agent 互動。
  3. 先做一個場景：讓 Agent 在界面裡幫用戶填表、跑流程，而不是只聊天。

變現角度：懂這套協議的開發者現在很少：接「把 Agent 嵌進現有產品」的單子，報價可以比普通前端開發高一檔；自己做產品則是差異化賣點。

6.Claude Trading Skills：給股票投資者的 Claude Code 技能包

一套給股票投資者的 Claude Code 技能：市場分析、技術圖表、財經日曆、選股篩選、交易策略開發，全部打包成 Skill，Claude Code 裝上就能用。

來源：GitHub · tradermonty/claude-trading-skills

3 步上手：
  1. 按 README 把技能裝進 Claude Code。
  2. 先拿一隻你熟悉的股票試跑：讓它做一次市場分析加技術圖表，對照你自己的判斷。
  3. 只把它當研究助手：結論自己拍板，別讓它直接替你下單。

變現角度：幫投顧、財經自媒體搭「AI 投研助手」，按月收費；自己用則是把重複的看盤、篩股流程自動化，省下的時間拿去寫內容、接諮詢。（提醒：這是研究工具，不是投資建議。）

7.Obsidian Prism：給 Google Antigravity 換一套黑曜石風工作台

孫可可 11 月 24 日推薦的開源項目：給 Google Antigravity 重新設計一套黑曜石風工作台界面，亮點是輸入框旁邊的 512K 上下文實時儀表——剩多少上下文、用了多少額度一眼看到。倉庫 11 月 17 日才建立，8 天已漲 500 多 stars。

來源：GitHub · RMvdesi/obsidian-prism

3 步上手：
  1. 先備份 Antigravity 的原有設置，確認一鍵還原能用。
  2. 照 README 安裝，開一個會話看上下文儀表是否正常顯示。
  3. 留意版本：目前是 v1.0.8-beta.1，Google 一更新就可能失效，先在小項目上用。

變現角度：Antigravity 插件生態正在爆發：會寫這類界面增強插件，就能接定製插件單；也可以把「幫團隊配好一套 Antigravity 工作流」做成付費服務。注意：這是獨立社區項目，與 Google 無關。

8.agy-fast：給 Antigravity 提速的 MCP 插件，作者稱省三成 token

Antigravity 的非侵入式 MCP 加速插件：不用改 Antigravity 本體，據作者實測可減少約 34% 的 LLM 對話輪次、31% 的 token 額度與 40% 的上傳流量。數字是作者自述，未經第三方驗證，先自己測了再信。

來源：GitHub · INK-Q/agy-fast

3 步上手：
  1. 照 README 安裝插件，不動 Antigravity 原有配置。
  2. 跑同一個任務對比開關插件前後的 token 用量，自己驗證省了多少。
  3. 有效再留著：把它寫進團隊的 Antigravity 標準配置裡。

變現角度：Antigravity 額度就是成本：幫重度用戶把 token 花費打下來，省下的錢分你一份就是現成的收費模式；也可以寫一篇實測對比文章引流。
