教程速遞｜2026-11-17

2026-11-17 · 猪猪侠玩AI · 共 17 篇，每篇附上手步驟和變現角度

1.Jane Street agent_skills：蘇格拉底式家教 Skill，逼模型教識你而唔係直接畀答案

Jane Street 首個公開 Skill 合集，圍繞共用的 SKILL.md 格式，只帶一個 Skill：socratic-tutor。佢會將語言模型變成一個嚴格的私人導師：先做診斷，再畫一張 0 到 5 級的技能地圖，之後逐題追問，唔會直接畀答案。11 月 12 日 GitHub 日榜衝上第 3 位。

3 步上手：
  1. 克隆 janestreet/agent_skills，讀 socratic-tutor 的 SKILL.md，理解診斷＋技能地圖的流程。
  2. 揀一個你想學的技能（例如 SQL 或期權定價），叫 Agent 先做診斷再出學習計劃。
  3. 學習時堅持「只問問題、唔畀答案」的模式，每完成一級先升級再進入下一級。

變現角度：「AI 家教」本身就是可賣的產品形態：將 socratic-tutor 的流程套入一個垂直領域（考證、面試、語言），做成收費學習助手；亦可幫培訓機構將現有課程改成蘇格拉底式互動版，按課程收費。

來源：GitHub janestreet/agent_skills

2.Claude-Cage：將 Claude Code 關入隔離虛擬工作台，唔怕 Agent 搞亂你部機

一個桌面工作台，將 Claude Code 同 Claude Desktop 放入隔離虛擬機運行，自帶代理網絡、時區同語言設定跟住出口節點，只共享你指定嘅文件夾。11 月 12 日 GitHub 日榜第 2 位。適合想放手畀 Agent 做嘢、又唔想佢掂到成部機嘅人。

3 步上手：
  1. 按倉庫 README 安裝 Claude-Cage，確認本地已裝 Claude Code 或 Claude Desktop。
  2. 只共享一個項目文件夾，唔好一次過開放成個 home 目錄。
  3. 喺隔離環境跑一次真實任務（例如重構一個小模組），核對輸出無問題再擴大授權。

變現角度：「安全隔離」係企業客戶最願意付費的一環：幫中小企業搭隔離 Agent 工作台，賣點是「Agent 搞壞都只限一個沙箱」；亦可寫成部署指南＋檢查清單，做成付費文檔產品。

來源：GitHub Lee-xeo/Claude-Cage

3.GoogleChrome/modern-web-guidance：瀏覽器廠商親自寫的現代 Web 指引 Skill

由 Chrome、Edge、Firefox 同 MDN 團隊共同維護的 Skill 合集：Agent 做任務時可以即時查閱的現代 Web 平台指引，確保佢寫的代碼跟得上今日的瀏覽器標準，而唔係憑過時記憶亂寫。11 月 12 日首次登上 GitHub 日榜第 4 位。

3 步上手：
  1. 將 modern-web-guidance 加入你 Agent 的 Skill 目錄，確認 Agent 識得喺做 Web 任務時調用佢。
  2. 開一個新前端任務，對比有／無呢個 Skill 時 Agent 寫出的代碼差異。
  3. 將最常用的指引（例如無障礙、性能）釘選為項目預設，要求 Agent 每次都先查閱。

變現角度：前端接案最常見的返工原因就係「代碼過時」：將呢個 Skill 納入接案流程，可向客戶承諾「按最新瀏覽器標準交付」，減少返工即係提高時薪；亦適合做成「AI 寫前端質檢」服務。

來源：GitHub GoogleChrome/modern-web-guidance

4.craft-anything：先研究人哋個 App 點解好用，再叫 Agent 照樣重建

思路好直接：先研究任何 App 或遊戲點解好用，再叫 Agent 重建佢。craft-anything 幫你拆解目標產品的交互同結構，再將拆解結果變成 Agent 可以執行的重建任務。11 月 12 日 GitHub 日榜新上榜項目。

3 步上手：
  1. 揀一個你欣賞的小產品（唔好揀太複雜的），用 craft-anything 跑一次完整拆解。
  2. 對照拆解報告，逐項核對 Agent 有無理解錯產品的核心機制。
  3. 叫 Agent 按拆解重建一個最小版本，跑得通再加功能。

變現角度：「拆解＋重建」係最快的學習同接案路徑：幫客戶將競品拆解成可執行的重建清單，按項目收費；自己做產品時，先拆解三個同類產品再動手，失敗率會低好多。

來源：GitHub storytold/craft-anything

8.將 ChatGPT 新 Wallet 變成免費賺錢助手：綁卡、自動化、Reddit 展示三步走

9.Reddit 真實 2026 技術棧：用 AI 做副業項目，唔係靠一個工具

整理 r/SideProject、r/sidehustle 同 r/OpenAI 的真實討論：Reddit 上的建造者唔係用一個魔法工具，而係跑一小套組合——ChatGPT 或 Claude 做架構同規劃、Cursor 或 Copilot 寫代碼、Notion AI 管計劃，愈來愈多人用 Emergent 一次過生成前後端、數據庫同部署。文章提醒：AI 消除咗寫代碼的瓶頸，但無消除產品瓶頸。

3 步上手：
  1. 先用一句話講清「解決邊個人的咩問題」，講唔清就唔好開始寫代碼。
  2. 按組合分工：Claude 做規劃、Cursor 做重構、Emergent 做全棧生成，唔好一個工具打天下。
  3. 將省返來的時間花喺驗證需求上：去目標社群發帖，睇下有無人願意付錢。

變現角度：「技術棧」本身可以賣：將你驗證過的組合寫成一份帶價格同踩坑記錄的清單，做成付費指南；或者幫客戶按呢套組合搭第一個 MVP，按項目收費。

來源：AI Tool Discovery

10.Vibe Coding 點樣真正賺錢：賣畀 vibe coder 先賺到錢

根據 TrustMRR／Stripe 核驗數據：仍然掛喺 Lovable、Replit、Vercel 或 Netlify 子域名下的 App，只有 7.6% 有月收入，無一個突破 $1K；但賣畀 vibe coder 的產品，一半有收入，12.2% 過去 30 日收入逾 $1K。結論好直接：賣技能、賣畀 vibe coder，或者幫本地商家做網站，先賺到錢；淨係發佈一個 App 等人嚟，基本賺唔到。

3 步上手：
  1. 唔好再以「發佈 App」為目標，改為「搵一個願意付錢的人」為目標。
  2. 三條最穩的路：幫本地商家做一頁網站（$500–1,000 一次性＋每月維護費）、賣模板或工具畀 vibe coder、賣你的 vibe coding 技能（教學、代做）。
  3. 每做完一個，先將收入數字記低，唔好憑感覺判斷邊條路得。

變現角度：呢篇文章本身就是一堂定價課：最穩的錢來自服務（幫人做網站），其次是賣工具畀同行，最唔穩係等 App 自己賺錢。想快速有收入，先接服務單，再將服務流程產品化。

來源：BigIdeasDB

16.孫可可：AI 世界的供需割裂——五個缺口就係五個生意

孫可可指出 AI 世界供需割裂：想學 AI 的人找不到靠譜引導及同伴；企業主找不到懂 AI 做自動化工作流的人；做 FDE 的人有 AI 本領但找不到客戶；做 AI 創業的人想學流量及自媒體；做 AI 自媒體的人日日發幹貨，卻未做成可直接幫客戶解決問題的解決方案。

3 步上手：
  1. 對照五個缺口，揀一個你最接近的供需兩端。
  2. 用一週時間做最小驗證：幫一個真實客戶解決一個具體問題。
  3. 將驗證過程寫成案例，作為獲客素材。

變現角度：每個缺口都係生意：最快的是「幫企業主做自動化工作流」——客戶有預算、問題具體、按項目收費；其次是「幫 FDE 搵客」，抽成或按月收費。

17.良竹：AI 涉及花錢，必須強制人工二次確認（400 元教訓）

良竹的教訓帖：佢讓 GPT 複刻十幾個短視頻做網站案例，因 Prompt 把兜底方案全寫進上下文（先用 Google Flow 的 Omni 1.2 免費出樣片，唔得再切付費 API 調 Kling／Seedance 2.5），結果賬號積分不足、自動切換 Google Flow 賬號又失敗，AI 跳過免費階段狂調付費 API 重試，3 分鐘花了 400 多元，生成的全是廢片。
