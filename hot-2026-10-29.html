1.Mistral Large 4 权重上线：1 万亿参数的欧洲开源旗舰来了

10 月 29 日 Mistral 在 Hugging Face 上线 Large 4 的权重。这款 1.05 万亿参数的 MoE 模型每 token 约激活 52B 参数，相比三周前预览版又多做了三周基于客户反馈的强化学习，官方称最终版更锐利。10 月初的预览 API 定价为输入每百万 token 1.36 美元、输出 4.18 美元。

来源：AI News Hub（10 月 29 日实时快讯）

对你有什么用：先拿 API 跑你自己的任务做对比，再谈自托管：万亿权重光是显存与运维就是一笔账。对做 Agent、出海应用的人来说，又多了一个非中美体系的强开源选项，选型时议价权变大了。

2.谷歌 Gemini 4 Carbon 发布：新基准榜上 1 分反超 Claude

10 月 28 日谷歌发布 Gemini 4 Carbon，定位编码、网络安全与可耗时数小时的复杂推理，称是迄今最强的谷歌模型。在 Artificial Analysis 的 Intelligence Index v5 上，Carbon 得 59 分，领先 Claude Opus 5.5 的 58 分与 OpenAI GPT-6 Astra 的 57 分；初期仅向部分网络安全机构开放。

来源：News9Live

对你有什么用：1 分差距别当购买指南：榜单由 9 项评测构成，没有模型全项领先。做长任务、代码与安全类项目的可以等开放后实测，日常任务先看价格与延迟，别为榜首多付钱。

3.谷歌 DeepMind 推出 Genie 4：会发声、会对话的世界模型

10 月 28 日 Google DeepMind 推出世界模型 Genie 4：用户边操作，它边实时生成可交互的世界画面，同时生成声音与对话，初期只给受信任测试者。后续计划通过 Gemini API 与 AI Studio 提供早期访问。这意味着世界模型从“看视频”走向“进世界里玩”。

来源：AI News Briefing（10 月 28 日）

对你有什么用：做游戏、仿真训练、互动内容的人，现在就该去排队申请并研究交互范式：等模型全面开放时，拼的不是谁先知道，而是谁已经想好第一个可玩场景。

4.韩国推理芯片 FuriosaAI 完成 6.2 亿美元 D 轮，估值 29 亿美元

10 月 28 日韩国 AI 推理芯片公司 FuriosaAI 宣布完成 6.2 亿美元 D 轮，投后估值 29 亿美元，投资方包括韩国国家成长基金、Naver、Cisco Investments 等。公司主打为推理专门设计的芯片，赌的是：当 Agent 反复调用模型时，生成回答的成本会成为比训练更大的账单。

来源：TechStartups（10 月 29 日融资汇总）

对你有什么用：推理成本就是 AI 应用的利润线。专用芯片竞争越激烈，明年 token 价格越可能继续下探；做应用的人现在就该把“可换模型、可换供应商”写进架构，别被一家绑死。

5.ChatGPT Pro / Business 订阅者每月可领最高 500 美元 API 额度

据 10 月 29 日的汇总，OpenAI 已向 ChatGPT Pro 与 Business 订阅者开放 API 额度：Pro 按档位每月对应 100、200 或 500 美元；Business 工作区按标准席每月 20 美元、高级席 100 美元累计，单个工作区每月上限 500 美元，额度按账单周期过期，且不覆盖经 API key 使用的 Codex。

来源：ExplainX（10 月 29 日汇总，引 OpenAI API 额度指南）

对你有什么用：已经在付 Pro 订阅的人，先去把 API 组织绑定领额度，再决定要不要另买 API 额度。跑小项目、做自动化原型时，这笔额度足够先把 MVP 跑通，不用一上来就为用量焦虑。
