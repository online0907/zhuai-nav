教程速递｜2026-10-20

2026-10-20 · 猪猪侠玩AI · 11 篇，每篇附上手步骤与变现角度

1.rea：让 Agent 逆向任何软件——看到喜欢的功能，直接让 AI 拆给你看

GitHub 今日涨星 1.3 万+、总星 34.4 万的爆款。把编码 Agent 接到 Hopper / Ghidra 等逆向工具上，无需源码就能分析 App、二进制、Electron 应用，讲清某个功能是怎么实现的，并给出证据和结论边界。

3 步上手：
  1. 装好 Node.js 22+，运行 npx rea-agents setup，按提示注册到 Claude Code / Codex / Cursor / Gemini CLI；
  2. 对 agent 说"分析 XX 软件的搜索功能，讲清原理并给出证据"；
  3. 终端也可用 npx rea-agents analyze-javascript-application <路径> --json 直接分析。

来源：github.com/morluto/rea

变现角度：帮客户/老板做竞品功能拆解报告收费；把"XX 热门功能是怎么做的"做成付费专栏或视频——比纯讲概念的内容稀缺 10 倍。

2.cleanyourtv：15 分钟把安卓电视变成"无广告 Apple TV"

上线 3 天 9668 星、TechCrunch 报道的"vibe coding"代表作。用 ADB 脚本备份电视、禁用厂商遥测/广告/预装（不卸载，可一键还原），再装一个 390KB 极简启动器，支持小米 / TCL / 索尼等 107 款机型。

3 步上手：
  1. 电视端：设置 → 关于 → 连点 7 次版本号开开发者选项，打开 USB 调试（保持同一 Wi-Fi）；
  2. 电脑上把仓库的 PROMPT.md 粘给 Claude Code，填上电视型号；
  3. 电视上点"允许 USB 调试"，按清单勾选要保留的应用和桌面 4 个常用 App，约 15 分钟搞定。

来源：github.com/Gathin23/cleanyourtv

变现角度：本地上门 / 远程"电视净化"服务收 50–100 元一次；把过程拍成短视频——"帮爸妈去掉电视广告"是极强共鸣的选题。

3.dsh-our-free-model：在 dsh 里免登录白嫖 DeepSeek V4.1 Flash、Kimi K3

3 万星的 dsh 插件：装上即用，无需登录、注册、填 API Key，模型清单跟随上游（OpenCode Zen / Kilo AI 公共网关）实时刷新，还带用量看板、OpenAI 兼容本地转发端口和工具输出压缩省 token。

3 步上手：
  1. 先装好 DeepSeek Harness（dsh）；
  2. 只从仓库 Release 下载发布包安装——注意 npm 上有个同名第三方冒名包，装了得不到官方构建；
  3. 重启 dsh，模型选择器里直接用免费模型。

来源：github.com/Ebony-Vinyl/dsh-our-free-model

变现角度：把 API 成本打到零，RAG / 小应用先跑通 MVP；给小团队搭"零成本 AI 工作台"收部署费。

4.Filee：按住 Ctrl 拖文件到格式圆环，244 种格式离线互转

7570 星的开源文件转换器：按住 Ctrl（macOS 按 Option）拖文件，光标处弹出格式圆环，拖到目标格式即转。图片 / PDF / Office / 电子书 / 音视频 / CAD / 3D 全覆盖，离线运行不上传，还带命令行和监控文件夹批量转。

3 步上手：
  1. 从仓库 Releases 下载对应系统的安装包；
  2. 按住 Ctrl 把文件拖到圆环上的目标格式（如 HEIC→JPG、PDF→DOCX）；
  3. 常用批量任务用 filee convert *.png --to webp -o converted，或设监控文件夹自动转。

来源：github.com/KnifeLemon/Filee

变现角度：闲鱼 / 淘宝接"文档批量转换、字幕格式互转"单；给自媒体团队搭"素材自动转码"流程收服务费。

5.strix：开源 AI 渗透测试，自动发现并修复应用漏洞

7 万星的开源 AI 渗透测试工具，自动发现应用漏洞并给出修复方案，网络安全 + AI 自动化双风口，目标用户是安全工程师和开发者。

3 步上手：
  1. 按仓库 README 部署 strix；
  2. 把自己的网站 / 应用指给它做一次完整扫描；
  3. 按报告逐项修复，高危先行。

来源：gitdiscover.org · usestrix/strix

变现角度：给独立开发者、小公司、出海团队做"安全体检"按次收费；把常见漏洞修复整理成清单 / 课程卖。

6.headroom：给 Agent 瘦身——压缩上下文，JSON 省 60–95% token

7.6 万星的开源工具，压缩 Agent 读到的工具输出、日志、文件和 RAG 片段再喂给模型：官方称编码 Agent 省 20% token、JSON 省 60–95%，答案不变。提供库、代理、MCP 三种接入方式。

3 步上手：
  1. 按 README 选库 / 代理 / MCP 方式接入你的 Agent 工作流；
  2. 跑一遍真实任务，对比压缩前后的 token 账单；
  3. 固化为默认链路，长期省钱。

来源：gitdiscover.org · headroomlabs-ai/headroom

变现角度：直接省 API 钱——重度用户每月能省下一大笔；给 AI 应用团队做"成本优化"咨询，按节省额分成。

7.skillhub：Agent 变多后，你需要一个"技能注册表"

讯飞开源的自托管 Agent 技能注册表（DEV 深度解析）：技能发布带版本管理、可回滚可锁定；RBAC 权限控制哪个 agent 能调哪个技能；每次调用留审计日志。解决"技能散落各仓库、版本失控、权限全开"的团队痛点。

3 步上手：
  1. 按文章指引自托管部署 skillhub；
  2. 把团队散落的 skill 打包发布为版本化技能包；
  3. 给不同 agent 配置 RBAC 权限，开通审计日志。

来源：DEV · When Agents Become a Fleet

变现角度：企业 Agent 落地的"技能治理"方案是真实付费点；先吃透这套，你就是稀缺的 Agent 架构顾问。

10.@HaileyAILabs 实测：Gemini 4 Argon vs Opus 5.5，3D 场景谁更强

@HaileyAILabs 用古希腊神话 3D 城市反复打磨对比：Gemini 4 Argon token 消耗不多、擅长做场景规模；Opus 5.5 更懂"把场景做漂亮"。选模型别只看参数，看你要什么。

3 步上手：
  1. 同一提示词，分别跑 Gemini 4 Argon 和 Opus 5.5；
  2. 对比"规模感"vs"精致度"两个维度；
  3. 按需求选：大场景铺量用 Argon，要出片交付用 Opus 5.5。

来源：X · @HaileyAILabs

变现角度：接 3D 场景/游戏美术外包时，选对模型 = 省 token 钱 + 交付质量；把这类对比做成内容，本身就是流量。

  3. 接单前先验证全流程可用，别等交付时才发现被墙。

来源：X · @HaileyAILabs

变现角度：避坑本身就是价值——做"AI 出海工具开户/网络避坑"咨询；给客户交付前先做可用性检查，你的服务费就收得更硬气。
