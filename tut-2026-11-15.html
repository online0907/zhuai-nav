教程速遞｜2026-11-15

2026-11-15 · 猪猪侠玩AI · 共 15 篇，每篇附上手步驟和變現角度

1.agent-browser：給 AI Agent 一個能一步步指揮的瀏覽器

Vercel Labs 的 Rust 命令行工具，讓 AI Agent 一條命令接一條命令地操作真實瀏覽器，而不是一次性丟個 URL 讓它自己猜。11 月 8 日當週熱榜上單日新增 812 星、總星數 47,470，是當週 Agent 瀏覽與控制類最受關注的項目。

3 步上手：
  1. 按倉庫 README 安裝 agent-browser，確認命令行能打開一個頁面。
  2. 讓你的 Agent 用「打開頁面 → 找元素 → 點擊 → 讀結果」這種細粒度命令跑一個任務，而不是一次給完整目標。
  3. 把跑通的命令序列存成腳本，下次同類任務直接複用。

變現角度：網頁自動化代做是最直接的接單場景——幫客戶把重複的網頁操作（填表、抓價、巡檢）寫成 Agent 腳本，一次收費、長期復用；這類工具出現得越早，越早入場的人越容易接到第一批單。

來源：MPDev GitHub Trending 榜單

2.FreeToken：在消費級顯卡上跑 290B＋ 參數 MoE 模型

加州大學伯克利分校團隊的邊緣原生 MoE 推理引擎，用頻寬自適應的 CPU-GPU 協同執行和語義感知緩存，讓 290B 以上參數的混合專家模型能在消費級遊戲顯卡上跑起來，不用租數據中心級算力。

3 步上手：
  1. 克隆 FlashML-org/FreeToken 倉庫，讀 README 確認你的顯卡與依賴是否滿足要求。
  2. 先用倉庫提供的示例模型跑通一次推理，記錄首 token 延遲和顯存佔用。
  3. 把你常用的開源 MoE 模型換上去，對比雲端 API 的單次成本。

變現角度：本地跑大模型的最大賣點是「數據不出本機＋不用按 token 付費」，適合接對隱私敏感的客戶（律所、診所、小企業內部知識庫）；能幫客戶把雲端賬單砍掉的部署服務，本身就能收費。

來源：GitHub FlashML-org/FreeToken

3.impeccable：一個讓 Agent 寫出「無可挑剔」代碼的技能包

11 月第一週 GitHub 熱榜項目，定位是給編碼 Agent 用的質量技能：讓 Agent 在寫代碼時自動對照一套高標準檢查清單，減少低級錯誤和返工，適合已經在用 Claude Code、Codex 這類工具的人疊加使用。

3 步上手：
  1. 克隆 pbakaus/impeccable，讀 README 了解它覆蓋哪些檢查維度。
  2. 把它作為 Skill 裝進你常用的編碼 Agent，跑一個你熟悉的小項目對照前後差異。
  3. 把檢查清單裡和你業務相關的部分抽出來，寫進自己的項目規範。

變現角度：代碼質量是接單的隱形門檻——能穩定交付「不用返工」的代碼，接單價就能往上談；把這類技能包整合進自己的交付流程，本身就是一種差異化賣點。

來源：GitHub pbakaus/impeccable

4.11 月 GitHub 漲星最快的 39 個 AI 倉庫，一次看完

作者 11 月 12 日拉取 GitHub Trending 月榜，逐個核對後留下 39 個主業是 AI 的倉庫，按月漲星數排名：第一名 VoiceStudio 單月漲 50,619 星（本地版 ElevenLabs，語音克隆＋配音＋有聲書），第二名 Cloudflare 安全審計 Skill，第三名 stablyai/orca 多 Agent 編排。榜單附每個倉庫的總星數與許可證，適合一次摸清本月風向。

3 步上手：
  1. 打開榜單，從前 10 名裡挑 1–2 個和自己方向相關的倉庫。
  2. 讀倉庫 README 的一句話定位，確認是框架、插件還是模型。
  3. 本地裝一個跑通最小示例，再決定是否用到自己的副業項目裡。

變現角度：月榜等於「開發者正在為什麼點星」的晴雨表；熱門倉庫周邊的教程、部署服務、二次開發都是可接的活，越早跟進競爭越少。

來源：Medium

5.n8n＋OpenClaw＋Kronos：作者自述月入 $3K 的 AI 自動化系統

作者從賬戶只剩 47 美元起步，用 n8n 做編排、OpenClaw 做推理層、Kronos 做行情預測、x402 做按次付費，搭出一套跑信用修復爭議信和行情預測的系統。實測數字（博主自述）：347 封爭議信經 n8n 發出，89 封經 x402 付費，每封 0.5 USDC、成本約 0.03 美元；信用修復收入 2,100 美元，VPS 每月 6 美元。文章坦言前期全是報錯和熬夜，沒有速成。

3 步上手：
  1. 在 6 美元／月的 VPS 上自託管 n8n，克隆開源的 n8n-claw 集成腳本跑通第一個流程。
  2. 把一個你熟悉的重複任務（發郵件、填表、生成文檔）做成 n8n 工作流＋OpenClaw 推理節點。
  3. 先給自己或一個熟人免費跑兩週，確認穩定再談收費。

變現角度：這套架構的賣點是「按次付費＋自動化」：x402 讓 Agent 調用也能收錢，適合把一次性的自動化能力包裝成按次收費的服務；但注意作者的收入數字是自述，照做前先小規模驗證，別直接辭職 all in。

來源：Mild High Radio

6.創業者把 8 份工作交給 AI 的順序與真實賬單

這篇不只列工具，而是給出交接順序和價格：先從免費套餐起步，每週交接一份工作，只在免費額度不夠用時才付費。按作者 11 月 3 日核對的定價算，前幾週可做到 0 美元，第一筆真實賬單約每月 71 美元；另引摩根大通研究所數據：2025 年為 AI 付費的中小企業，月支出中位數約 28 美元。還提醒：承諾 AI 收入的宣傳是危險信號，美國 FTC 已就此起訴過相關公司。

3 步上手：
  1. 從清單裡挑第一份工作（通常是寫作或客服回覆），先用免費版跑一週。
  2. 記錄 AI 替你省下的時間和出錯次數，決定是否值得付費升級。
  3. 每週只交接一份工作，別一次全交出去——出問題時才找得到原因。

變現角度：這份清單本身就是接單地圖：中小企業主最缺的就是「按順序落地 AI」的人，你可以按這 8 份工作的順序打包成諮詢服務，一份工作一個收費包，幫客戶落地還能收月費。

來源：Gravity

7.2026 年 AI 副業的現實版圖：服務型先賺錢，產品型後賺大錢

作者綜合多家數據源對比了 2026 年 AI 副業的真實情況：服務型（聊天機器人搭建、內容代做、自動化諮詢）1–4 週就能有第一筆收入，產品型（通訊、YouTube、圖庫）要 3–12 個月；大多數嘗試者 60 天內放棄且零收入。具體價位：聊天機器人搭建每單 250–500 美元＋每月 50–200 美元維護費；LinkedIn 代寫在 60 天內做到每月 3,000 美元以上（引述數據）；專家領域 AI 訓練時薪 200 美元以上，通用任務只有 12–25 美元。

3 步上手：
  1. 先選服務型起步：挑一個你本來就懂的行業，給 3 家本地小店免費做一次 AI 客服或內容樣品。
  2. 拿到第一個付費客戶後，把交付流程寫成標準操作文檔。
  3. 服務跑順了，再把沉澱下來的方法做成產品（模板、課程、工具）賣第二遍。

變現角度：結論很明確：急著見錢就賣服務，有耐心就做產品；最賺錢的組合是「服務先收錢、產品後放大」。別一上來就做產品熬 12 個月沒收入，先讓服務養活自己。

來源：Jake's Insights

8.賺第一個 1,000 美元的現實路線圖：先賣服務，再談其他

作者明說不承諾「7 天賺 1,000 美元」，給的是一條誠實路線：先賣服務給已經有錢的企業，再讓內容和聯盟收入慢慢跟上。算術示例（非承諾）：1,000 美元可以是 5 個 200 美元的客戶、10 個 100 美元的客戶，或 1 個 1,000 美元的打包單；新手每天投入幾小時，1–2 週內得到第一個回覆，再過幾週拿到第一筆訂單，整體約 1–3 個月。

3 步上手：
  1. 只選一個服務＋一個客戶群（例如給房產中介做短視頻），做出 3 個樣品。
  2. 帶著樣品去聯繫 10 個潛在客戶，報價 100–200 美元／條。
  3. 拿到第一單後，把樣品和報價流程固定下來，再去談第二個客戶。

變現角度：這份路線圖的價值在於「不畫餅」：它把第一個 1,000 美元拆成可執行的客戶數和報價，適合當作自己的起步檢查表，而不是收藏了就忘的雞湯。

來源：AI Income USA

9.1,145 次提交、收入 $0：一場 AI 自己賺錢實驗的誠實日記

一個小項目讓 AI Agent 從 7 月開始嘗試自己賺錢，到 11 月 15 日倉庫已有 1,145 次提交，記錄在案的收入是 0 美元。最有啟發的是 Upwork 實測：10 月 29 日至 11 月 4 日發出 25 份提案，到 11 月 9 日結算時只有 2 份被查看（8% 查看率），沒有任何有效回覆。作者是 Agent 本人寫日記，人類負責賬號和身份驗證，承諾後續繼續如實記錄，包括下一個零。

3 步上手：
  1. 把這個案例當作反面教材：先讀它記錄的提案方式，看看問題出在哪。
  2. 自己發提案時，別只拼數量——25 份提案 2 次查看，說明提案本身沒有打中客戶痛點。
  3. 給自己的副業也建一個「第一美元日誌」，每週記錄做了什麼、得到什麼回覆。

變現角度：這篇的價值是「誠實」：AI 自動化不等於自動賺錢，獲客環節才是瓶頸。想靠 Agent 賺錢的人，先解決「怎麼讓客戶回覆你」，再談自動化交付，順序反了就是 1,145 次提交換 0 美元。

來源：Medium

10.孫可可轉發：創業別只抄工具，要去研究用戶卡在哪裡

孫可可 11 月 15 日轉評 Koda 的創業帖：大佬教的「先模仿再超越」有兩個坑——你只能抄到選題和文案這些皮毛，人家的入場時機和讀者信任根本抄不走；等人家火了你再照搬，大家早就看膩了，抄得再像也拿不到那個結果。孫可可的補充是：應該多去研究用戶卡點的解決方案，而不是只悶頭研究 AI 工具。

3 步上手：
  1. 列出你目標用戶最近卡住的三個具體問題（不是「想要 AI 工具」這種泛泛的需求）。
  2. 針對其中一個卡點，用現成 AI 工具做出一個能直接用的解決方案樣品。
  3. 拿著樣品去問 5 個目標用戶：這個能不能解決你的問題，願意為什麼樣的結果付錢。

變現角度：工具會過時，卡點不會——賣「解決某個卡點」比賣「會用某個工具」更值錢。接單時報價也要按解決的問題收費，而不是按用了什麼工具收費。

來源：X @Sunkeke_AI

11.孫可可轉發：西堂從 AI 副業到創業，兩年半做到月入 10 萬的播客復盤

孫可可 11 月 15 日轉發的視頻播客，講前騰訊程序員西堂的兩年半：2024 年 Sora 刷屏後拉兩個小夥伴做 AI 視頻，日更公眾號三十天，接到第一單政府商單，十天一萬多；商單接不過來就用培訓找人，第一個產品一週加了四十個人；2025 年搬到線下，八個月無休，五個人幹六件事；後來做 AI 漫劇，承製太累就做減法、主做培訓；再到公眾號商單，單價從三四千漲到一萬，搭起寫手和賬號的 MCN，還寫了一本賣了九萬冊的書。月入 10 萬為播客標題口徑（博主自述）。

3 步上手：
  1. 先聽完整期播客，記下西堂每個階段的轉折點（商單 → 培訓 → 漫劇 → MCN）。
  2. 對照自己的現狀，判斷你現在處在哪個階段，下一階段需要補什麼能力。
  3. 挑一個最小的下一步：接一單商單，或開一次小範圍培訓，先驗證需求再擴大。

變現角度：這條路徑的關鍵詞是「做減法」：承製太累就轉培訓，培訓跑通再搭 MCN——每個階段都只做當下最賺錢且最可持續的事，而不是同時鋪六條線。對一個人創業來說，這比盲目擴張更值得抄。

來源：X @Sunkeke_AI

12.Hailey 實測：用 Grok Bot 四步復刻爆款「屏幕維修喵」短片

一隻小貓被困在手機屏幕裡拿電鑽修裂屏的 AI 短片在 Ins 上爆火，發佈幾小時就有幾萬播放。Hailey 11 月 15 日分享了用 Grok Bot 復刻的方法，還附了完整提示詞：9:16、15 秒、3D 皮克斯風格的小橘貓、迷你電鑽、低頻敲擊聲與貓叫聲，重點是控制貓咪在屏幕內部的空間關係和軟件變形細節。

3 步上手：
  1. 把爆款參考視頻鏈接丟給 Grok Bot，讓它拆解畫風、鏡頭、動作和特效。
  2. 保留核心創意，重新設計貓咪造型、維修工具和修復動作，生成分鏡參考圖。
  3. 按分鏡生成 15 秒短片，檢查角色一致性、動作銜接和音效，不滿意的鏡頭單獨重做。

變現角度：爆款復刻是最快的起號方法：一個驗證過的創意＋換皮，就能批量出片。接短視頻代做或自己做賬號時，先從復刻開始，再慢慢加入原創元素，別一上來就追求完全原創。

來源：X @HaileyAILabs

13.Hailey 連載：真人 × 2D 動漫短片 EP02，「二次元分身回不去了」

Hailey 11 月 15 日更新的真人 × 2D 動漫腦洞短片第二集：真人主角的二次元分身劇情繼續失控，延續 11 月 14 日 EP01 的設定。這類「真人出鏡＋動漫分身互動」的格式，把真人賬號的信任感和動漫內容的傳播力拼在一起，是目前 AI 短片裡辨識度很高的一條路線。

變現角度：「真人＋分身」格式適合做個人 IP：真人建立信任，分身負責傳播和趣味。接品牌短片或做自己的賬號時，這種高辨識度的格式比純 AI 生成更容易被記住，也更容易接到商單。

14.想風轉發：花 50 塊錢讓 AI 手搓了一款背單詞肉鴿遊戲，還開源了

15.想風轉發：100 美元、7 小時，Fable 5.2 做出一套電腦組裝套件廣告片

想風 11 月 15 日轉發 Mr Tactical 的 Fable 5.2 作品：一支電腦組裝套件（PC BUILD KIT）廣告片，9 個零件、零人工組裝，全程由 Fable 5.2 生成，畫面文字「9 PARTS / 0 HANDS REQUIRED / ASSEMBLED BY FABLE 5.2」。作者標註的成本是 100 美元、7 小時——這是一條可參考的 AI 廣告片成本基準。

3 步上手：
  1. 以「100 美元／7 小時」為基準，記下自己目前做一條同類廣告片的成本。
  2. 找一個有實物的產品，用 Fable 5.2 或同類工具跑一條 15–30 秒的組裝／展示短片。
