教程速递｜2026-11-04：11 篇 AI 干货教程

2026-11-04 · 猪猪侠玩AI · 每篇附 3 步上手与变现角度

1.GitHub 热榜被 Skill 占领：先读一篇，再决定装哪一个

11 月 2 日当周 GitHub 热榜 16 个项目里有 9 个是给 Claude Code、Codex 等编码 Agent 的 Skill 或支架：Superpowers、Hallmark、Impeccable、Cloudflare 安全审计 Skill、claude-mem、Karpathy 的 CLAUDE.md 等。

来源：Medium（逐条核对 README）

3 步上手：
  1. 只按你本周要交付的东西选一类：做网页选设计类 Skill，做交付选流程类 Skill。
  2. 先读 README 的触发条件和限制，再安装，别一次装十个互相打架。
  3. 用一个小任务实测一轮，能省时间才留进常用库。

变现角度：把“选型 + 实测 + 清单”做成面向开发者的付费专栏或咨询，先帮团队省下试错时间。

2.Claude Code 11 月 3–4 日更新：Skill 只改了两行，两个 Skill 库却在涨星

Claude Code 2.1.317 只修了一个 Skill 同步问题，2.1.318 没有 Skill 条目；同期 mattpocock/skills 当日新增约 1100 星、Claude Code Game Studios 新增约 1180 星，前者是工程师个人工作流合集，后者是 49 个 Agent、70 多个 Skill 的游戏工作室框架。

来源：Medium（核对官方 changelog 与热榜）

3 步上手：
  1. 升级前先看 changelog，确认你的 Skill 不会被同步问题影响。
  2. 从 mattpocock/skills 里只抄与你工种对应的 2–3 个 Skill。
  3. 想做游戏类交付时，再按 Game Studios 的分工拆任务。

变现角度：把“版本更新解读 + 可直接抄的 Skill 清单”做成周更内容，面向付费订阅或社群。

3.n8n + Claude 自动发 X：4 个节点跑通算法友好的内容流水线

用 n8n 的定时触发 + Claude API + 代码节点 + X 发帖节点，可以自动生成并发布符合 X 排序权重的帖子：回复、引用、分享的权重远高于点赞，复制链接权重更高，书签不计权重。

来源：Espressio

3 步上手：
  1. 在 n8n 里搭定时触发 → Claude 生成草稿 → 代码节点截断到 280 字 → X 发帖。
  2. 给 Claude 的提示词里写明“先给结论、留一个可回复的钩子”。
  3. 先跑一周人工审核模式，数据稳定后再放开自动发布。

变现角度：帮内容号、品牌号搭这条流水线，按月收维护费；注意 X 发帖已改为按量付费，报价前先算清 API 成本。

4.n8n 官方 AI 工作流生成器：用一句话让 Claude 帮你建工作流

n8n 内置的 AI 工作流生成器、内置 MCP 服务器和官方 Skill 库，可以让 Claude 直接在你的 n8n 实例里新建、修改工作流，2.18.3 以上版本可用，免费自托管社区版也包含 MCP 能力。

来源：Lemlist

3 步上手：
  1. 把 n8n 升到 2.18.3 以上，开启内置 MCP 服务器并连接 Claude。
  2. 用一句话描述目标和输入输出，让它先生成草稿工作流。
  3. 逐个节点检查凭证和字段，跑一次测试数据再上线。

变现角度：给中小企业做“口头提需求、当天出自动化”的交付，按工作流数量收费，比卖课更快回款。

5.Claude 线索打分不编造、不重发：先做证据校验，再谈自动化

一个 2000 美元预算的线索项目启示：表单只收姓名、邮箱、公司、需求；用邮箱 + 原文做哈希去重；Claude 输出必须附原文引证，引证对不上就判为未知；跟进文案必须经人工确认才发。

来源：n8n 社区

3 步上手：
  1. 表单字段收窄，只留打分必需的信息。
  2. 加哈希去重和引证校验两个节点，挡住重复与幻觉。
  3. 发信前加人工审批节点，审批通过才真正发出。

变现角度：这套“防幻觉 + 防重发”正是 B 端客户愿意付费的点，做成线索自动化标准包去接单。

6.在 VPS 上跑 Claude + n8n：三个现成工作流，先算清 Token 账

在自有 VPS 的 n8n 里可以跑摘要 Webhook、定时读资讯并写表、能自己调 API 的 Agent 三类工作流；关键是按节点选模型、防止提示词里出现未定义变量、给重试循环设上限，避免一夜跑掉几千次。

来源：SSD Nodes

3 步上手：
  1. 先在 VPS 上部署好带 HTTPS 的 n8n，密钥只存凭证不写进节点。
  2. 先跑摘要 Webhook 一个工作流，验证成本与稳定性。
  3. 再上定时资讯流和 Agent 流，每个循环都加次数上限。

变现角度：把“VPS + n8n + Claude”打包成个人和小型团队的自动化托管服务，按月收费。

7.Reddit 实测过的副业：先分“啤酒钱”和“房租钱”，再选赛道

Reddit 多个版块的共识是：低门槛副业大多每月只赚 150–400 美元；用户测试约 15–20 分钟 10 美元，AI 数据标注类常被报 20–25 美元/小时，但项目供给波动大，别按满负荷算收入。

来源：LifeJourney（整理 Reddit 多版块讨论）

3 步上手：
  1. 先在 r/sidehustle 看方法，再去 r/workonline 核对实操细节，最后去 r/scams 查坑。
  2. 选一个 2 周内能拿到第一笔钱的，先验证再放大。
  3. 按“每月 150–400 美元是常态”做预算，别按博主截图做计划。

变现角度：把“已验证副业清单 + 避坑清单”做成低价资料包，卖点是诚实预期而不是暴富承诺。

8.周末做一个微型 AI SaaS：不做“AI 全能”，只做一个人的一个痛点

用 Cursor、Replit 加 Claude 这类工具，周末就能做出一个面向窄人群的 AI 小工具；常见定价在每月 19–49 美元，关键是先找到一个已经有人付费解决的具体问题，而不是先做产品再找用户。

来源：SimuJobs

3 步上手：
  1. 选一个具体人群和一个具体任务，例如“给房产中介写房源描述”。
  2. 周末做出最小可用版，只留核心功能和付费入口。
  3. 先找 10 个目标用户收反馈，付费意愿确认后再加功能。

变现角度：窄人群订阅制是微型 SaaS 最稳的模型，10 个每月 30 美元的用户就是 300 美元月收入的起点。

变现角度：把“插件清单 + 安装避坑”做成给新创作者的入门包，搭配内容号引流。
