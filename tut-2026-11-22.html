教程速遞｜2026-11-22

2026-11-22 · 猪猪侠玩AI · 每天更新 22 篇

1.RTK：一個指令代理，幫你壓縮 AI 寫程式時的 Token 消耗

寫程式時 AI Agent 會把終端機輸出全文塞進上下文，Token 燒得很快。RTK 是一個命令列代理，專門壓縮指令輸出再交給大模型，支援多種開發指令與工具，11 月 22 日當天登上 GitHub 熱榜，累計 87.4K Stars。

來源：GitHub · rtk-ai/rtk

3 步上手：
  1. 第 1 步：按倉庫 README 安裝 RTK，把它設為你常用開發指令的代理入口。
  2. 第 2 步：照常用 Claude Code 等工具跑建置、測試或查日誌，讓 RTK 先壓縮輸出再送進模型。
  3. 第 3 步：對比前後 Token 用量，挑輸出最臃腫的指令重點壓縮，長期固定下來。

變現角度：直接省 API 費用：Token 用量下降等於每個任務成本下降，接案或跑自動化時利潤率即時提升；亦可寫成慳 Token 實測文章引流。

2.OpenMotion：開源版 CapCut＋Claude Motion，參考影片一鍵變可編輯動態設計

上載一條參考影片，OpenMotion 會把它變成可編輯的動態圖形，套用品牌套件後輸出 MP4，直出 YouTube、Shorts、Reels 與 TikTok。內置 300 多份 Motion.md 指引，支援 Claude Code、Codex 等 22 個 Agent，8 日內新增 4,978 Stars，累計 14,976 Stars。

來源：GitHub · nexu-io/openmotion

3 步上手：
  1. 第 1 步：Clone 倉庫，按 README 啟動全端工作室，設定好品牌顏色、字體與 Logo。
  2. 第 2 步：上載一條參考影片，讓 Agent 生成可編輯的動態圖形版本。
  3. 第 3 步：在編輯器微調文字與節奏，輸出各平台尺寸的 MP4 成品。

變現角度：接短影片剪輯與動態設計單：同一套品牌模板可批量出片，按條收費；亦可做自媒體頻道的片頭與轉場包出售。

3.Taste Skill：畀 AI 寫程式員一點品味，告別千篇一律的 AI 式網頁

AI 生成的網頁往往一眼就認得出：同款紫色漸變、同款排版。Taste Skill 是一組 Agent Skill，為寫程式 Agent 提供美術指導、參考圖片與瀏覽器驗收檢查，令成品不再是 generic AI 風格。8 日內新增 3,698 Stars，累計 119,916 Stars。

來源：GitHub · Leonxlnx/taste-skill

3 步上手：
  1. 第 1 步：按 README 把 Skill 裝進 Claude Code、Cursor 或 Codex 等 Agent。
  2. 第 2 步：生成網頁時附上參考圖與品牌風格要求，讓 Agent 按美術指導出稿。
  3. 第 3 步：用瀏覽器檢查步驟驗收成品，逐版對比，沉澱一套自己的風格指引。

變現角度：提升接案交付質素：同樣時間交出更好看的落地頁，可收更高報價；亦可打包「AI＋品味」工作流做教學或模板出售。

5.Inference Optimisation Skill：令本地大模型伺服器跑得更快，專治推理慢與食記憶體

本地跑大模型最痛是推理慢、啟動慢、食爆記憶體。這個 Agent Skill 專門做本地 LLM 伺服器調優：解碼、推測解碼、預填、KV 快取、啟動時間與量化全覆蓋，用基準測試加爬山法自動找最佳配置。11 月 16 日建立，至 22 日已獲約 1,650 Stars。

來源：GitHub · sybil-solutions/inference-optimisation-skill

3 步上手：
  1. 第 1 步：Clone 倉庫，固定模型、硬件、提示詞集與上下文長度做基準。
  2. 第 2 步：記錄冷啟動時間、首字延遲、Token 間延遲、吞吐量與峰值記憶體。
  3. 第 3 步：讓 Skill 逐項調參做爬山優化，保留可複現的最佳配置。

變現角度：省雲端推理費：本地跑得順就唔使長期租 GPU；亦可為中小企做本地 AI 部署調優顧問服務。

變現角度：做 AI 開發流程顧問：幫團隊落地「Agent 寫程式＋人工把關」的交付管線，按項目收費；亦可寫部署實測內容引流。

13.點樣令 AI Agent 推送前先問你：DigitalOcean 實測，權限規則要咁寫先有效

作者實測 DigitalOcean Managed Agents 的權限規則：第一次規則完全冇觸發，Agent 54 秒、10 次工具調用就寫好 12 個測試、推送分支兼開咗 PR；第二次前後加萬用字元先至攔得住。兩次 Token 成本分別只係 0.13 美元與 0.05 美元。

來源：DEV · remdore

3 步上手：
  1. 第 1 步：喺 Session 規格寫權限規則，預設允許，只把推送、開 PR 等指令設為要問。
  2. 第 2 步：跑一次真實任務，查日誌確認有冇出現 human_input_requested；零請求即係規則失效。
  3. 第 3 步：模式前後加萬用字元，例如 *git*push*，並限制 Session Token 權限，雙重保險。

變現角度：安全交付是收費服務的賣點：識得幫客戶鎖死 Agent 權限，可接企業自動化單；實測記錄亦是高質內容素材。

15.向 AI 爬蟲收費：HTTP 402 中間件，每頁收 0.002 美元，約 10 行程式搞掂

AI 爬蟲免費食你網站內容，呢個 r/SideProject 項目反其道而行：用 HTTP 402 狀態碼加 x402 協議向 AI 爬蟲逐頁收費，每頁 0.002 美元。站長設定錢包地址與自訂費用，經 Cloudflare Workers 或 Express 中間件約 10 行程式即可接入，普通訪客完全唔受影響。

來源：Founderr Pulse（源自 r/SideProject）

3 步上手：
  1. 第 1 步：讀原文連結的 Reddit 帖，確認中間件的接入方式與收費邏輯。
  2. 第 2 步：喺自己網站用 Cloudflare Workers 或 Express 接入，設好錢包地址與每頁費用。
  3. 第 3 步：先小範圍測試，確認人類訪客與搜尋引擎唔受影響，再全面開啟。

變現角度：內容站直接變現：AI 爬蟲流量變成按頁收費的收入；亦可幫內容站客戶部署收費，收安裝加維護費。

16.用 AI 做收費副業的正確順序：先搵人哋肯畀錢解決的問題，唔係先開內容帳號

前騰訊、百度 AI 產品負責人 Andy 寫的副業方法論：把收費副業當成有範圍的服務賣，唔係開內容帳號等運到。關鍵係買家、交付物、價格、排除項與交付流程五樣齊全，先用少量真實買家驗證再擴大。建立與測試期每週約需 4 至 6 小時專注時間。

來源：AndyAwake · a6no1.cn

3 步上手：
  1. 第 1 步：揀一個人哋已經肯畀錢解決的問題，寫清買家係邊個、交付物係乜、幾時交貨。
  2. 第 2 步：定三個價：最低可接受價、目標價、拒絕或改範圍的條件。
  3. 第 3 步：每週固定做目標清單、簡短診斷對話、提案與跟進，先搵少量真實買家驗證。

變現角度：直接賣服務變現：AI 幫你慳研究、起草與製作時間，你保留判斷與客戶溝通，賺的是解決問題的錢，唔係賣工具的錢。
