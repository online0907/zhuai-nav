1.6 小時免費課：從零學 Claude Code，17 個模組、7 個實戰項目

Benjamín Cordero 在 YouTube 發佈的免費 Claude Code 課程更新版，全程 6 小時以上、17 個模組、52 個主題、7 個邊做邊學的實戰項目。內容覆蓋 Claude 生態選型（Chat、Cowork、Design、Code）、安裝到上線第一個網站、把重複工作寫成 Skill、MCP 接 Gmail／Notion／Meta Ads，以及用 Ultra Code 與 n8n 做 24 小時自動化；全程用自然語言操作，不需要編程基礎。

來源：Creador De Contenido 課程導讀（2026-11-17）

3 步上手：
  1. 裝好 Claude Code 桌面版，跟課程第 1 模組走完安裝與第一個網站上線。
  2. 挑一個你每週重複做的任務（如寫報價、寫腳本），照課程寫成第一個 Skill。
  3. 把 Skill 接進 n8n，讓它定時跑起來，先從一個流程驗證再擴展。

變現角度：學完可接「Claude Code 落地」代做單：幫小商家把重複流程寫成 Skill 或自動化，按項目收費；課程本身免費，成本只有時間。

2.Claude Code 寫 n8n 工作流：不用手動連節點，3 分鐘出初版

作者實測：把手動流程口述給 ChatGPT 整理成指令，再交給 Claude Code，約 3 分鐘就得到可在 n8n 打開的工作流。關鍵組合是 Claude Code＋n8n MCP 服務器＋n8n Skills：MCP 提供節點文檔與模板，Skills 教 Claude 怎麼正確調用；生成後仍需人工核對憑證、模型選擇與表達式，確認無誤再啟用。

來源：Nate Herk 新手指南

3 步上手：
  1. 裝 Claude Code，接上 n8n MCP 服務器與 n8n Skills 包。
  2. 用一句話講清你要自動化的流程（觸發條件、輸入、輸出到哪裡）。
  3. 讓 Claude 生成工作流 JSON 並寫入你的 n8n 實例，逐項核對憑證與節點參數再啟用。

變現角度：一個工作流過去手工要 2–4 小時，現在 10 分鐘級別出初版；可按單接中小企業的 n8n 自動化外判，或打包成「每週自動化」訂閱服務。

3.研究轉行動：用 Claude＋n8n 把更新日誌變成每日簡報

一份從零可跟的入門教程：盯住一個版本發佈或更新日誌 feed，n8n 每天定時抓取過去 24 小時的新內容，交給 Claude 按固定格式寫成簡報，再推送到你真正會看的地方。附可直接導入的 workflow JSON，Perplexity 研究為可選補充，不建議作為第一信息源。

來源：Techitional 指南（2026-11-16）

3 步上手：
  1. 導入附帶的 workflow JSON，或按教程逐個節點搭建。
  2. 把 feed 換成你關心的來源（如競品更新日誌、行業新聞源），接好 Anthropic API 憑證。
  3. 設定每日早上定時執行，輸出推到 Telegram 或郵箱，先跑一週驗證簡報質量。

變現角度：同一套路可賣「競品監控簡報」服務：幫客戶盯對手動態，每月收訂閱費；也能做成自己的行業資訊產品。

4.GitHub 熱榜風向：Agent 開始搶辦公軟件與協作協議

11 月 15 日當週 GitHub 熱榜顯示，編程 Agent 的熱度正擴散到通用生產力工具：Univer（辦公 SDK，文檔／表格／幻燈片／數據庫／無限畫布，人與 AI 可同時實時編輯）當日漲星過千；AG-UI（Agent 與前端雙向通信的事件協議）被稱為「Agent 的 TCP/IP」；Plannator 在 Agent 執行前後加一層人工審核；另有 Chrome DevTools MCP 與阿里開源的 Open Code Review 上榜。

來源：MPDev GitHub Trending 週報（2026-11-15）

3 步上手：
  1. 先試 Univer 或 AG-UI 的官方 demo，判斷是否適合你的產品形態。
  2. 把 Plannator 的「執行前人工審核」思路抄進自己的 Agent：高風險動作先停下來等人確認。
  3. 用 chrome-devtools-mcp 讓 Agent 直接讀瀏覽器狀態，取代截圖猜測。

變現角度：辦公場景是 Agent 落地最容易收費的方向：基於 Univer 做「AI 協作表格／文檔」小工具，或給企業搭帶審核層的 Agent，都是明確的收費點。

5.GitHub AI 週報第 14 期：安全審計 Skill 一週漲星 10,700

GitHub AI Weekly 第 14 期（11 月 14 日）按週漲星排出 Top 10：Cloudflare 的 security-audit-skill 一週漲 10,700 星居首，是一個可做多階段安全審計的編程 Agent Skill；其餘上榜者包括 OpenMausBot、Matt Pocock 的 skills 合集、Vercel agent-desktop、Anthropic 官方 skills，以及 NVIDIA 的 Auto Ontology（把數據庫元數據編成業務術語本體，供查詢 Agent 查閱）。

來源：AI Beyond：GitHub AI Weekly Issue 14

3 步上手：
  1. 裝 Cloudflare security-audit-skill，對自己的項目跑一次多階段審計，看報告是否可落地。
  2. 從榜單挑一個與你工作流最貼近的 skill（如 agent-desktop），跑通一個小任務。
  3. 把好用的 skill 收進自己的技能庫，下次同類任務直接調用。

變現角度：安全審計、合規檢查是企業願意付費的剛需：學會用這類 skill 跑審計，可接「AI 安全體檢」外判單，按次收費。

6.Claude 被封怎麼辦？五套平替方案整理（X 挖礦）

@Sunkeke_AI 轉發 @kongge_space 的整理：針對 Claude 帳號被封的用戶，給出五套平替方案。第 1 套是直接買海外 Mac mini 或雲服務器；其餘四套在時間線未完全展開，詳情見原帖。適合正被封號困住、急需恢復工作流的人先對照自查。

來源：@Sunkeke_AI（轉發 @kongge_space，2026-11-19）

3 步上手：
  1. 先確認被封原因與申訴可能性，別急著重複註冊新號。
  2. 按原帖對照五套方案的成本與門檻，選一套先跑通最小可用工作流。
  3. 把常用提示詞與工作流備份到本地，避免再次被封時從零開始。

變現角度：帳號風控是剛需痛點：懂平替與遷移的人可以做「AI 工具遷移」諮詢，幫被封用戶一小時內恢復工作流，按次收費。

7.新 X 算法下怎麼做內容：頭三行放最有用一句（X 挖礦）

@Sunkeke_AI 总结新 X 算法打法：寫可轉進群的乾貨、頭三行放最有用一句、勿催轉發或複製連結、勿用 AI 批量回覆、一次只發一條、專注原創並認真回覆、爆款 48 小時內跟進同類內容。

來源：@Sunkeke_AI（2026-11-19）

3 步上手：
  1. 下條帖子先寫頭三行：把最有用的結論放最前面，再展開細節。
  2. 刪掉「求轉發」「連結在評論」這類話，改成內容本身值得轉進群。
  3. 發完 48 小時內看數據，表現好的主題立刻跟進一篇同類內容。

變現角度：X 流量是變現漏斗的入口：算法偏好原創乾貨＋認真回覆，堅持這套打法漲的是精準粉，後續接諮詢、賣課、賣模板都更容易轉化。

11.AI 短劇總被滑走？多半是聲音問題，參數全公開（X 挖礦）

@xaiwind 引用 Miller 文章：AI 短劇被滑走常因聲音問題；9 段素材剪成 4 分鐘成片，聲音、調色、字幕參數全公開，附剪輯技能包。

來源：@xaiwind（2026-11-19）

3 步上手：
  1. 先檢查你上一條短劇的聲音：音量、混響、人聲清晰度，對照原帖參數逐項調整。

  3. 用同一套參數再做一條，對比完播率變化，確認哪個參數最有效。

變現角度：AI 短劇的變現拼的是完播率：聲音修好、留存上來，才能接廣告與帶貨；這套參數也可打包成剪輯服務，幫短劇創作者批量優化。
