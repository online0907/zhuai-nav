1.用 Orca 让 5 个 AI 编程助手并行干活

stablyai/orca（截至今日约 9.5 万 star，MIT 协议）：AI Agent 编排器，让 Claude Code、Codex、Grok 等几十种 coding agent 在各自独立的 git worktree 里并排运行，一个界面统一管理，还能用手机 App 远程监控进度。官方主打「一条 prompt 发给五个 agent」。

项目地址：https://github.com/stablyai/orca

上手 3 步：
  1. ① 去 onorca.dev 下载对应系统版本（Mac 可用 brew 安装）；
  2. ② 打开 Orca，登录你已有的 Claude/Codex 订阅账号；
  3. ③ 新建 worktree，把任务发给多个 agent 并行跑，手机装 companion App 随时看进度。

变现角度：接外包或做副业时，一个人同时开 5 个 agent 并行干活，交付速度翻几倍；适合批量跑代码审计、网站改版这类按单收费的活。

2.零成本给视频配音：开源 ElevenLabs 平替 VoiceStudio

debpalash/VoiceStudio（截至今日约 7.2 万 star，AGPL-3.0 协议）：开源、完全本地运行的声音工具——声音克隆、视频配音、听写、转录、有声书制作，支持 646 种语言。本地运行意味着零 API 成本。

项目地址：https://github.com/debpalash/VoiceStudio

上手 3 步：
  1. ① 一条命令安装（官网 install 脚本，Windows 用 PowerShell 版本）；
  2. ② 打开 Voice cloning，选内置演示声音或上传一段干净的参考录音；
  3. ③ 输入文字、按提示装好模型，点生成。

变现角度：接有声书制作、短视频配音、播客剪辑的单子时边际成本几乎为零。注意 AGPL-3.0 对商用有条件限制，接单前先看清协议。

3.让 AI 秒变「科研助手」：177 个科学 agent skills

K-Dense-AI/scientific-agent-skills（截至今日约 5.2 万 star，MIT 协议）：177 个科研专用 AI agent skills（生物、化学、医药、药物发现、数据分析等），让 Cursor、Claude Code、Codex 秒变「AI 科学家」，自带 100+ 科学数据库。

项目地址：https://github.com/K-Dense-AI/scientific-agent-skills

上手 3 步：
  1. ① 用 npx 一条命令把 skills 装进你的 agent（支持 Cursor、Claude Code、Codex 等）；
  2. ② 在 agent 里直接下指令，比如「做一组单细胞 RNA-seq 分析」；
  3. ③ 按 skill 自带的验证步骤检查结果（README 特别强调 validation checks，别跳过）。

变现角度：面向科研/医药/高校人群做「AI 科研助手」代运营或咨询——帮实验室搭文献综述、数据分析流程。这类客户付费能力强、竞争少，是冷门高价值赛道。

4.抄作业：用 AI 求职框架 69 投拿下 20 个一面

MadsLorentzen/ai-job-search（截至今日约 4.9 万 star，MIT 协议）：跑在自己电脑上的 AI 求职框架，基于 Claude Code，自动搜职位、评估匹配度、定制简历、写求职信、准备面试。作者本人用它投了 69 份定制申请、拿到 20 场一面，2026 年 6 月成功入职 AI 工程师——真实战绩。

项目地址：https://github.com/MadsLorentzen/ai-job-search

上手 3 步：
  1. ① Clone 仓库（作者建议用私有仓库而非公开 fork，因为 setup 会把个人简历写进 tracked 文件）；
  2. ② 装好 Claude Code + Python 3.10 + Bun，运行 tools/install_portal_clis.py；
  3. ③ 在 Claude Code 里依次跑 /setup（填简历）→ /scrape（搜职位）→ /apply（投递）。

变现角度：直接做「AI 求职代投/简历优化」服务——帮别人跑这套流程按单收费。注意内置职位搜索是丹麦市场，国内用需要换成本地招聘网站技能。

5.Anthropic 官方插件目录：在插件生态刚起步时占位

anthropics/claude-plugins-official（截至今日约 4.1 万 star，Apache-2.0 协议）：Anthropic 官方维护的 Claude Code 高质量插件目录，分官方插件和第三方社区插件两类。

项目地址：https://github.com/anthropics/claude-plugins-official

上手 3 步：
  1. ① 在 Claude Code 里运行 /plugin 进 Discover 浏览插件；
  2. ② 用 /plugin install {插件名}@claude-plugins-official 安装；
  3. ③ 想自己开发就看 plugins/example-plugin 参考实现，按 plugin.json 规范打包，通过目录提交表单申请收录。

变现角度：典型的「卖铲子」机会：开发解决某个垂直场景的 Claude Code 插件，提交进官方目录拿曝光，再用插件引流卖自己的服务或课程。插件生态刚起步，先发优势明显。
