教程速递｜2026-10-25

2026-10-25 · 猪猪侠玩AI · 11 篇 AI 干货，附上手步骤和变现角度

1.infinite-canvas：AI 创作的无限画布，生图、视频、助手全在一块板上

GitDiscover 10 月 25 日每日精选第一名：开源无限画布工作台，集成 AI 生图、参考图编辑、视频生成、对话助手、提示词库与素材管理，支持可视化创作流程与多 Agent 协同，兼容 OpenAI 接口生态。9K star，单日新增 376 star。

来源：GitDiscover（basketikun/infinite-canvas，10 月 25 日精选）

3 步上手：
  1. 按仓库说明部署或打开画布，先熟悉一块画布里的生图、参考图编辑与视频生成入口。
  2. 接上你已有的 OpenAI 兼容接口渠道，把提示词库与素材管理用起来，别只当白板用。
  3. 拿一个真实创作任务（比如一组短视频封面）全流程跑一遍，确认从灵感到成图不用跳出画布。

变现角度：给短视频、电商、自媒体客户做“画布式”素材交付：一次出图成套、过程可视，比单张出图更好报价；也可以把常用画布模板打包成资料卖。

2.openpencil：第一个 AI 原生的开源矢量设计工具，提示词直接变 UI

自称全球第一个开源 AI 原生矢量设计工具，也是第一个支持多 Agent 团队并发协作的设计工具：设计即代码，提示词直接在实时画布上生成 UI，被称为 Pencil 的现代替代品。6.6K star，10 月 25 日仍在增长。

来源：GitDiscover（ZSeven-W/openpencil，10 月 25 日精选）

3 步上手：
  1. 按仓库说明启动 openpencil，先用提示词生成一个页面或海报初稿。
  2. 直接在画布上改布局、改文案，确认“设计即代码”的改动能实时回写。
  3. 导出给客户过一遍：重点看字体、间距与移动端适配，别只看首屏效果。

变现角度：接 UI、海报、落地页外包时，用它把“初稿”时间压到原来的零头，按套收费仍有利润；多 Agent 协作的卖点，适合接需要多人并行的小团队单子。

3.SolidCraft：纯 Rust 参数化 3D CAD，开源也能做正经建模

纯 Rust 写成的开源参数化 3D CAD 应用，支持桌面端、网页端，并可通过 MCP 做自动化。10 月 7 日发布，不到三周冲到 10.3K star、1.3K fork，增长曲线非常陡。

来源：GitDiscover（tangency-labs/solidcraft，10 月 25 日数据）

3 步上手：
  1. 打开网页端或桌面端，照着示例建一个参数化模型，改一个参数看整体联动。
  2. 试着用 MCP 把“改参数、出图”串成自动化流程，确认能批量出变体。
  3. 拿一个真实小物件（支架、收纳件、外壳）完整走一遍：建模、导出、检查尺寸。

变现角度：3D 打印、产品原型、手办配件类接单的利器：参数化意味着改一处全盘联动，批量出变体很快；按“模型 + 改版次数”打包收费，比按小时划算。

4.ds-harness-remote：手机也能远程操作你的 DeepSeek Harness 和 CodeX

基于 DeepSeek Harness 插件机制的多端远程访问方案：端到端加密、P2P 优先网络、低延迟，支持从 PC、Android 与 Web 随时访问并操作远程 Harness 和 CodeX。801 star，单日新增 331 star。

来源：GitDiscover（liguobao/ds-harness-remote，10 月 25 日数据）

3 步上手：
  1. 在远程主机上按仓库说明装好插件与服务端，确认 P2P 连接能通。
  2. 手机端与网页端各登录一次，试一次真实操作（比如查看任务、改一段代码）。
  3. 检查加密与访问权限：只放行你自己的设备，别把远程入口暴露给公网。

变现角度：给小团队、独立开发者提供“远程开发环境搭建”服务：一次部署、按月维护；出差、在家都能干活的卖点，对自由职业者尤其好卖。

5.Claude 连上 n8n：用嘴描述自动化，Agent 替你搭工作流

n8n 官方 MCP 集成让 Claude 可以直接调用你的工作流：MCP Server Trigger 节点把工作流暴露成工具，Claude 原生支持 MCP 客户端。作者称整套打通约 30 分钟，自托管 n8n 免费，n8n 云端约 $20/月起。核心分工是：你负责意图，Agent 负责接线；你审一遍再上线。

来源：DEV（Shaam，2026 指南）

3 步上手：
  1. 自托管 n8n 里启用 MCP Server Trigger，并按官方文档配好 Claude Code/Codex 的 Agent 技能。
  2. 让 Claude 列出可用节点，确认它能读到你的工作流，再口头描述一个小流程让它搭建。
  3. 跑一次测试、检查重试与异常分支，确认无误后再把自动触发打开。

变现角度：这是最适合接单的组合技：给小企业搭“线索到回复、订单到报表”的自动化，按流程收费；你卖的不是工具，是“不用再手动干这件事”。

6.n8n-skills：教 Claude Code 建“不出错”的 n8n 工作流，四分钟跑通

czlonkowski 的 n8n-skills 插件让 Claude Code 按规范建 n8n 工作流：装插件、测 MCP 连接（应看到 525+ 节点）、描述需求、审验证、部署测试。关键在三档验证：先用 ai-friendly 快速档，再用 runtime 中档，最后用 strict 生产档；每个技能自带 3 个以上测试场景。

来源：Bright Coding Blog（n8n-skills 完整指南）

3 步上手：
  1. 装好 Node.js 18+、Claude Code CLI 与 n8n（Docker 或云端），执行插件安装并配好 n8n-mcp。
  2. 先让 Claude 列出节点验证连接，再描述一个 webhook 分流流程（高优先级走 Slack、低优先级存 Airtable）。
  3. 按三档验证逐级过：检查硬编码密钥、缺失异常处理等红线，全部通过再部署。

变现角度：接单交付时把“strict 档验证通过”写进验收标准：客户买的不是一个能跑的工作流，而是一个经得起查的工作流，这就是你比同行贵一点的理由。

7.七步把年入 $1M 的生意交给 Claude Code：从 80 多件杂事降到每天 5、6 件

Nick Saraev 把一个年入约 $1M 的生意交给 Claude Code 做自动化：一周后，他每天只剩 5、6 件杂事，另外 80、90 件不再需要他。七步法是：一周屏幕观察审计（不是口头描述工作）、列出全部任务清单、做规划会、设评分目标的评估循环（大部分时间花在这里）、把胜出者固化成技能、批量测试（把一周迭代压到一天）、最后决定哪些排程、哪些保留人工。

来源：LinkedIn（Nick Saraev 自述，469 条评论）

3 步上手：
  1. 先做一周“屏幕观察”审计：让 Claude 看你实际怎么干活，列出你碰过的全部任务，别靠回忆写清单。
  2. 给每个任务设一个可打分的评估目标，迭代到分数达标再固化成技能，别凭感觉上线。
  3. 批量跑测试、排程胜出者，敏感环节保留人工确认，形成“自动 + 兜底”两层。

变现角度：把这套七步法做成企业自动化咨询产品：按“每周省下的工时”收费，而不是按工具收费；评估循环这一步最值钱，因为它决定了自动化会不会翻车。

8.Voxtral 3 语音 Agent 成本账：$0.04/分钟，建之前先算清这张表

Mistral 10 月 20 日发布的 Voxtral 3 语音栈，让“建还是买”第一次能用价格表直接算：批量转录 $0.0035/分钟、实时转录 $0.008/分钟、语音输出 $13/百万字符；整条语音 Agent 管道（听、推理、调工具、说，全程流式）配 Mistral Small 4 是 $0.04/分钟，换其他推理模型是 $0.08/分钟。作者提醒：按 5 万分钟/月算，$0.04 档约 $2,000/月（未含 token 费）。

来源：DEV（Shivay Singh Rajput，Voxtral 3 成本测算）

3 步上手：
  1. 先算你自己的分钟数：预估月通话量 × 平均时长，分别按 $0.04 与 $0.08 两档算总账，再对比现有供应商报价。
  2. 按 LiveKit 管道搭最小版本：转录 → 推理 → 工具（日历、CRM、订单查询）→ 语音输出，全程流式。
  3. 实测打断、转人工与多语言场景，确认延迟与准确率达标后再谈上线。

变现角度：电话客服、预约接待、订单查询类 Agent 可以按分钟或按月卖给小商家：成本表就是你的报价底稿，客户一看就懂“为什么比招人便宜”。

9.Laravel AI SDK 1.1 的 Agent 技能：指令越长，越要拆成“按需加载”的小文件夹

2026 年 10 月 5 日发布的 Laravel AI SDK 1.1 加入 Agent 技能：把 Agent 指令拆成一个个小文件夹，每个文件夹一个 SKILL.md；模型平时只看到名字与描述列表，判断相关时才读全文。好处是：退款规则、发货规则、语气规范不用每次请求全量发给模型，又省 token 又不容易互相干扰。

来源：DEV（Laravel AI SDK 1.1 技能搭建指南）

3 步上手：
  1. 升级到 laravel/ai ^1.1（需 PHP 8.3+、illuminate/support 12 或 13、symfony/yaml）。
  2. 在 resources/skills 下一技能一文件夹，SKILL.md 顶部写好描述，描述要写成“Use when…”触发句——因为模型先看到的只有它。
  3. 拿一个真实客服问题验证：模型是否只加载了相关技能、没加载无关规则。

变现角度：给已有的 Laravel 客户加 Agent 功能是最顺的升级单：不用换栈，按“技能包”收费；省下的 token 本身就是你能算给客户看的账。

10.Amoxi：用 TypeScript 写第一个 AI Agent，构建时就把接线错误拦下来

开源 TypeScript Agent 框架 Amoxi：@Tool 把方法变成工具（参数类型直接生成 schema 与校验），@Agent 是带 instructions() 与工具列表的类；每个 Agent 自带流式 HTTP API 与浏览器 agentChat()；approval: true 会在关键步骤停下来等人工拍板。亮点是脚本化模型测试：不用联网、不用等真实模型，几分之一秒就验证工具代码、接线与循环逻辑。

来源：DEV（karawash-projects，Amoxi 系列）

3 步上手：
  1. 按文档搭一个最小 Agent：一个工具类 + 一个 Agent 类，先跑通流式 HTTP 接口。
  2. 用脚本化模型写测试：验证工具接线、循环逻辑与审批暂停点，npm test 应在 1 秒内跑完。
  3. 把 approval: true 加到敏感工具上，确认人工拍板前 Agent 不会擅自执行。

变现角度：TS 团队接 Agent 开发外包时，构建时校验 + 快速测试就是交付质量的护城河：改动不怕改崩，客户敢把后续迭代也交给你。

11.免费课：用 Claude Code + n8n + GSD 从零做一个能收款的 SaaS

Class Central 收录的免费视频课：用 Claude Code 做编排、n8n 做自动化、GSD 做规划结构，完整走完一个 SaaS——从架构、环境搭建（VS Code、GitHub、Supabase、Vercel、Stripe）、登录鉴权、用户数据，到 AI 轮播图生成、用量统计与支付验证，最后部署上线。适合想把“会用 AI”变成“能卖产品”的人按课照做。

来源：Class Central（Build and Sell a SaaS 免费课程）

3 步上手：
  1. 跟课搭好三件套：Claude Code 编排 + n8n 自动化 + GSD 规划，接好 GitHub、Supabase、Vercel、Stripe。
  2. 先做一个最小可收款功能（登录 + 一个核心 AI 功能 + 支付验证），别先做全套界面。
  3. 跑通“用户付费 → 用量统计 → 功能开通”闭环，再谈扩功能与推广。

变现角度：这门课本身就是一条从 0 到收款的路线图：跟完课你手里就有一个可卖的 SaaS 骨架；也可以把“帮人按这套路线搭 SaaS”做成陪跑服务。
